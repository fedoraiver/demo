# 音效事件表

本文维护已接入声音事件的触发与去重合同，当前事件为菜单反馈。播放 ID 对应 `SoundCue::id()` 与[音频清单](audio_manifest.json)的 `assets[*].event_ids`，素材路径和播放策略由清单维护。

| 用户事件 | 播放 ID | 触发与去重合同 |
| --- | --- | --- |
| 菜单焦点 | `menu_hover` | 真实键盘／手柄导航改变焦点，或鼠标真实移动进入已有可操作按钮后一次。 |
| 菜单确认 | `menu_confirm` | 接受开始、打开页面、改变分类、实际调整设置、恢复默认、成功应用或退出请求后一次，打开暂停菜单也使用此事件。 |
| 菜单返回／失败 | `menu_cancel` | 返回、恢复运行、回主菜单或设置应用失败后一次。 |

菜单每帧只消费一项语义请求，只对接受的结果反馈一次。无效动作、当前分类重选和设置到达边界不发声。音量滑条仅在结束且最终值改变后确认一次，`Quit` 不等待声音播完。

静止光标、按钮内移动、页面重建产生的悬停状态和单按钮页面导航不播放焦点音。菜单冷却使用真实时间，在暂停状态中继续推进。

事件进入统一播放端，未加载、静音、冷却或并发限制使请求被丢弃，恢复音量或完成加载后不补播。运行时调度与混音见[音效数据流](../../docs/architecture.md#音效数据流)，设置预览与持久化见[使用说明](../../docs/usage.md#设置)。

素材维护见[音频管线](../../docs/audio.md)，许可与取得证据见[来源记录](ATTRIBUTION.md)，开发检查见[音频无窗口验证](../../docs/testing/README.md#音频无窗口验证)。
