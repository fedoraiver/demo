# 音效事件表

本文是声音反馈触发与去重合同的参考。播放 ID 与 `SoundCue::id()`、[运行时清单](audio_manifest.json) 的 `assets[*].event_ids` 对应；素材路径、增益、冷却和单素材并发以清单为准。

## 当前接入事件

| 用户事件 | 播放 ID | 触发与去重合同 |
| --- | --- | --- |
| 菜单焦点 | `menu_hover` | 真实键盘／手柄导航改变焦点，或鼠标真实移动进入已有可操作按钮后一次。 |
| 菜单确认 | `menu_confirm` | 接受开始、打开页面、改变分类、实际调整设置、恢复默认、成功应用或退出请求后一次；游戏中打开暂停也使用此事件。 |
| 菜单返回／失败 | `menu_cancel` | 返回、恢复运行、回主菜单或设置应用失败后一次。 |
| 拾取／游戏音效试听 | `parcel_pickup` | 成功建立持有关系后一次；失败拾取不播。Audio 页 `Test SFX` 单次请求同一素材，按 SFX 分类处理，不建立持有关系。 |
| 主动释放 | `parcel_release` | 主动解除持有关系后一次，不代表发生落地撞击。 |
| 包裹落地 | `parcel_land` | 每个 `FixedPostUpdate` 检查实际支撑接触：未持有包裹、向上支撑法线 `normal.y >= 0.65` 且法向冲量 `>= 1.8 kg m/s` 后一次；锁存到全部支撑接触结束，包括休眠接触。预测接触及初始小冲量不消耗后续真实撞击。 |
| 持握失稳 | `instability_warning` | 持有者建立或改变后宽限 0.5 秒；相对实际持握目标的位置误差 `> 0.65 m` 持续 0.35 秒后警告一次，恢复到 `< 0.45 m` 才重新允许警告。冷却遵循清单，正常拾取惯性不触发。 |

菜单每帧只消费一项语义请求，只对被接受的结果反馈一次。无效动作、当前分类重选、设置到达边界不发声；音量滑条拖动不连续确认，仅在释放且最终值改变后一次。`Quit` 不等待声音播完。

静止光标、按钮内移动、页面重建产生的悬停状态和单按钮页面导航不播放焦点音。落地与持握警告仅在实际运行的游戏会话中收集，主菜单和暂停不产生这两类新反馈。

## 预留素材与试听候选

下列名称只标识已有素材的语义，不表示已实现功能、接入计划或已确认玩法；具体触发由使用它们的实验确定。

| 播放 ID | 素材语义与边界 |
| --- | --- |
| `parcel_handoff` | 转交反馈。 |
| `cart_collision` | 通用金属撞击占位，不是推车移动实录。 |
| `character_bounce` | 回弹反馈。 |
| `delivery_success` | 成功反馈。 |
| `delivery_failure` | 失败反馈；菜单保存失败使用 `menu_cancel`。 |
| `ambience_island_placeholder` | 合成环境循环，仅独立试听页使用，不属于运行时 `SoundCue`，不预加载或默认播放。 |

## 播放与维护入口

事件请求进入统一播放端，加载、冷却、并发及静音限制都可能使请求被丢弃；不延后补播。调度、混音和播放限制见 [音效数据流](../../docs/architecture.md#音效数据流)，设置预览、应用和取消见 [使用说明](../../docs/usage.md#设置)。

更新素材或策略遵循 [音频管线](../../docs/audio.md)，文件与许可证证据见 [来源记录](ATTRIBUTION.md)，无窗口检查见 [验证指南](../../docs/testing/README.md#音频无窗口验证)。
