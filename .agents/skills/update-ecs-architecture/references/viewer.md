# 查看器与页面交互

在详情、选图、搜索、筛选交互、选择高亮、历史、焦点或浏览器资源维护前读取；调度筛选的集合语义与投影归[调度模型](schedules.md)，实际交互和协议验收归[视觉验收](visual-validation.md)。

## 卡片详情与源码

卡片右栏按[节点详情](../../../../docs/diagrams/README.md#节点详情)仅显示名称、完整 `description`、符合现有条件的“打开对象关系图”及源码位置。删除归属、注册参数、访问、Query、字段、组件清单、函数体操作明细及附带源码和清除选择按钮，不因显示范围删减共享数据。未选中时的图例及连线详情保持各自内容；卡片通过画布空白清除，连线详情的清除按钮保留。

同函数其他注册的独立身份和对象图按[声明与注册身份](object-model.md#声明泛型与注册身份)保留并可搜索。

源码编辑器、复制反馈、工作区与依赖定位遵守[源码定位验证](../../../../docs/testing/README.md#架构图源码定位验证)。

## 选图、默认调度与详情栏

查看器使用顶部选图，不保留左侧导航；Schedule 按应用分组，默认主应用 `Update`，缺失时选首个非空调度。Schedule 始终显示右侧说明栏，未选择时为当前图的英文 Graphviz 图例；鼠标左键单击系统、集合边框或标题、可见上下文卡片后显示可调整的右侧详情，并提供对象关系图入口，清除后回图例，不收起面板或桌面分隔条。

## 调度画布交互与对象绑定

左键拖动继续平移，左键单击 SVG 内外主画布空白清除选择，集合填充背景仍选中集合，调度依赖线、箭头和标签保持选择；右键、菜单键与 Shift+F10 使用浏览器菜单，Enter／Space 查看聚焦对象。交互只附加到页面 DOM，不改独立调度 SVG、DOT 或原模型。核对按应用、Schedule、原始图元身份及 DOT 哈希绑定，不按短名合并泛型、重复注册或匿名集合；集合成员须覆盖原成员边及 marker 传递，同步点和缺失目标保留真实类别。缺失对象依据锁定源码补完整说明、访问及一跳关系，不能以通用占位或基础单卡替代。

## 对象搜索与 Plugin 菜单

对象图保留选择、详情、图例、源码及可调整面板；全局对象搜索和旧聚合候选显示在顶栏浮层，不占用详情栏。插件菜单不单列“其他插件”，`WorldInspectorPlugin` 与 `EguiPlugin` 相邻；未列入菜单的对象仍可搜索或从旧链接访问，并显示为当前对象。菜单入口不改变真实装配或调度筛选目录。

## 视角与 Plugin 默认选择

两类图均支持平移、缩放、适合窗口及历史恢复；Plugin 菜单、搜索、对象图及普通链接入口进入对应 Plugin／PluginGroup 单卡图并默认未选中，显示 Mermaid 图例；有效显式 `node`、卡片激活和选中历史仍显示说明。清除恢复图例，不通过中心兜底重新选中插件；其他对象默认选择不改。

## URL 条件与历史

核对 `schedule`、重复的 `scheduleIncludePlugin`／`scheduleExcludePlugin`、兼容的系统与文本筛选参数、`scheduleNode`、`object`、`node` 及来源上下文；条件实际变化立即更新 URL 并新增一次历史，批量操作一次、相同条件零次。实时筛选与异步完成保留下拉、搜索词、滚动位置、焦点及旧条件候选，不以完整导航重置筛选控件。视角只关联实际成功呈现的条件；未完成或失败的历史条件返回时重排并适合窗口。核对选择和空白清除均只替换当前历史、打开对象图后返回调度选择与视角；成功筛选仅清除已不可见的选择，失败保留成功画面与详情。

## 筛选控件与旧链接迁移

切 Schedule 后仍可取消没有本图系统的已选组及旧条件；检查逐项选择、批量选择当前搜索结果中有系统的组、单栏及全部清空。旧总览进入默认调度，旧插件链接的有效节点进入精确对象，无节点时进入插件对象，旧 component 与聚合候选继续迁移。保留 workspace、其他参数和片段，兼容使用历史替换。

## 焦点与反馈

焦点、面板、搜索、选择恢复及复制反馈按图的说明与验证参考检查，不让选择或 `paint` 抢其他控件焦点。

## 左键命中与清除

全部 SVG 的卡片及对象图连线统一鼠标左键选择；未拖动且释放位移不超过 `6px` 时按释放坐标命中，合成点击不得重复激活。触摸点按不选择，平移缩放和页面控件保留。鼠标命中须区分可选对象、非交互图元和真正画布背景，不能把所有未选中命中都当空白；画布外、空命中和控件不处理。复用清除路径，保留视角、搜索文本／历史查询、筛选及对象页的返回来源 `scheduleNode`；历史恢复和筛选迟到结果不得使已清高亮复活。

## Graphviz 包装与集合高亮

调度图穿过 Graphviz 的 `g`／`a` 包装寻找当前对象轮廓，遇到子对象、边和标题层时停止；复用对象图选中填充、增粗与蓝色外圈，不给文字或嵌套系统施加集合滤镜。集合标题共指主体、无独立 Tab 停靠或选中框。

## 集合遮线背景与高亮回归

标题遮线背景须按已有绑定与 `data-cluster-id` 精确关联，作为仅填充的伴随图元同步主体选中色，保存并恢复原填充及优先级；不移除遮线背景、不按标题名称匹配，也不为背景增加描边或滤镜。

默认及筛选重排共用此路径，自动覆盖全部真实集合的选择、缩放与恢复。使用真实包装及全部调度绑定断言实际填充、描边和滤镜变化，不以选择类或详情代替高亮检查。

## 图例状态

默认视图与实际筛选结果的 `legendKinds` 随成功呈现一并更新，隐藏 marker 不作为对象；零结果保持右栏并显示图例空状态，失败及迟到结果不替换已显示内容。

## 按需资源、缓存与 Worker

浏览器只拿必要共享目录与目标视图，不重复内嵌全部图及模型；缓存最多八张，加载失败与迟到结果不得破坏选择、图例或历史。

默认 SVG、对象图和逐视图元数据从本地服务按需读取，Schedule 筛选使用内嵌 Graphviz WASM Worker，仅允许同源文档资源请求，不加载 CDN、额外字体或 WASM。核对 Worker 复用、取消、过时响应、SVG 安全检查与失败时的静态图恢复；分发内嵌运行库时保留对应许可证与来源说明。
