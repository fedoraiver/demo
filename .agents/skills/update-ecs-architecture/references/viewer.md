# 查看器与页面交互

在详情、选图、搜索、筛选交互、选择高亮、历史、焦点或浏览器资源维护前读取；调度筛选的集合语义与投影归[调度模型](schedules.md)，实际交互和协议验收归[视觉验收](visual-validation.md)。

## 卡片详情与源码

卡片右栏按[节点详情](../../../../docs/diagrams/README.md#节点详情)仅显示名称、完整 `description`、符合现有条件的“打开对象关系图”及源码位置。卡片说明不展示归属、注册参数、访问、Query、字段、组件清单、函数体操作明细及附带源码和清除选择按钮，不因显示范围删减共享数据。未选中时的图例及连线详情保持各自内容；卡片通过画布空白清除，连线详情的清除按钮保留。

同函数其他注册的独立身份和对象图按[事实与身份](object-model.md#事实与身份)保留并可搜索。

源码编辑器、复制反馈、工作区与依赖定位遵守[源码定位验证](../../../../docs/testing/README.md#架构图源码定位验证)。

角色标题不与条目标签重复，不为消除界面重复改写原始来源记录。取真实编译器 `sourceEntries` 的脱敏样本执行生成页的真实源码编辑器，覆盖扩展 Windows 依赖根及缺失、非法目录；定位与不可用原因仍可见，不能退回项目目录。测试不以桩编辑器或仅 URI 正确代替页面接入回归。

## 选图、默认调度与详情栏

选图控件位于顶部，页面不设左侧导航；Schedule 按应用分组，默认主应用 `Update`，缺失时选首个非空调度。Schedule 始终显示右侧说明栏，未选择时为当前图的英文 Graphviz 图例；鼠标左键单击系统、集合边框或标题、可见上下文卡片后显示可调整的右侧详情，并提供对象关系图入口，清除后回图例，不收起面板或桌面分隔条。

## 调度画布交互与对象绑定

左键拖动平移，左键单击 SVG 内外主画布空白清除选择，集合填充背景仍选中集合，调度依赖线、箭头和标签保持选择；右键、菜单键与 Shift+F10 使用浏览器菜单，Enter／Space 查看聚焦对象。交互只附加到页面 DOM，不改独立调度 SVG、DOT 或原模型。核对按应用、Schedule、原始图元身份及 DOT 哈希绑定，不按短名合并泛型、重复注册或匿名集合；集合成员须覆盖原成员边及 marker 传递，同步点和缺失目标保留真实类别。缺失对象依据锁定源码补完整说明、访问及一跳关系，不能以通用占位或基础单卡替代。

## 对象搜索与 Plugin 菜单

对象图保留选择、详情、图例、源码及可调整面板；全局对象搜索和别名候选显示在顶栏浮层，不占用详情栏。插件菜单不单列“其他插件”，`WorldInspectorPlugin` 与 `EguiPlugin` 相邻；未列入菜单的对象仍可搜索或通过有效对象链接访问，并显示为当前对象。菜单入口不改变真实装配或调度筛选目录。

## 视角与 Plugin 默认选择

两类图均支持平移、缩放、适合窗口及历史恢复；Plugin 菜单、搜索、对象图及普通链接入口进入对应 Plugin／PluginGroup 单卡图并默认未选中，显示 Mermaid 图例；有效显式 `node`、卡片激活和选中历史仍显示说明。清除恢复图例，不通过中心兜底重新选中插件；普通对象图默认选中中心，高密度入口按下面的目录规则。

## 高密度关系列表

按[高密度对象关系](../../../../docs/diagrams/README.md#高密度对象关系)验证完整目录、搜索、单条关系原生绘图及完整 SVG／Mermaid 导出。目录默认只读元数据，不提前加载巨大全图或绘图库；选中后复用节点、边详情与当前成功图的图例。核对 `objectRelation`、`objectMode`、目录搜索与滚动的历史恢复，未知关系、空结果、完整图切换、清高亮与返回目录的区别，以及快速切换、等待期间清除、失败重试和 BFCache。键盘导航必须将聚焦行滚入可见区域，退出目录后先恢复画布显示再转移焦点。

## URL 条件与历史

核对 `schedule`、重复的 `scheduleIncludePlugin`／`scheduleExcludePlugin`、兼容的系统与文本筛选参数、`scheduleNode`、`object`、`node` 及来源上下文；条件实际变化立即更新 URL 并新增一次历史，批量操作一次、相同条件零次。实时筛选与异步完成保留下拉、搜索词、滚动位置、焦点及已保存的条件候选，不以完整导航重置筛选控件。视角只关联实际成功呈现的条件；未完成或失败的历史条件返回时重排并适合窗口。核对选择和空白清除均只替换当前历史、打开对象图后返回调度选择与视角；成功筛选仅清除已不可见的选择，失败保留成功画面与详情。

## 筛选控件与链接解析

切 Schedule 后仍可取消没有本图系统的已选组及已保存的筛选条件；检查逐项选择、批量选择当前搜索结果中有系统的组、单栏及全部清空。未指定对象或有效节点的 `feature=overview` 链接进入默认调度；Plugin 的 `feature` 链接有有效 `node` 时进入对应对象，无节点时进入对应 Plugin 对象；`component` 参数与对象别名按当前目录解析，多个匹配时显示候选。保留 workspace、其他参数和片段，规范化使用浏览器历史替换。

## 焦点与反馈

焦点、面板、搜索、选择恢复及复制反馈按图的说明与验证参考检查，不让选择或 `paint` 抢其他控件焦点。

## 左键命中与清除

对象图按[画布交互与焦点](../../../../docs/diagrams/README.md#画布交互与焦点)依据当前图的真实显示端点计算严格一跳聚焦：选中节点仅保留其直接边与邻居，选中边仅保留该边及两端，清除恢复全图；不从邻居或注册对象的访问字段继续扩张。路径、箭头、边标签及背景同步淡化，实体标题按真实 owner 同步，避免嵌套重复淡化。Schedule 的选中行为独立保留。纯状态计算、页面接入和实际 SVG 有效透明度分别回归，不能只检查类名。

全部 SVG 的卡片及对象图连线统一鼠标左键选择；未拖动且释放位移不超过 `6px` 时按释放坐标命中，合成点击不得重复激活。触摸点按不选择，平移缩放和页面控件保留。鼠标命中须区分可选对象、非交互图元和真正画布背景，不能把所有未选中命中都当空白；画布外、空命中和控件不处理。复用清除路径，保留视角、搜索文本／历史查询、筛选及对象页的返回来源 `scheduleNode`；历史恢复和筛选迟到结果不得使已清高亮复活。

## Graphviz 包装与集合高亮

调度图穿过 Graphviz 的 `g`／`a` 包装寻找当前对象轮廓，遇到子对象、边和标题层时停止；复用对象图选中填充、增粗与蓝色外圈，不给文字或嵌套系统施加集合滤镜。集合标题共指主体、无独立 Tab 停靠或选中框。

## 集合遮线背景与高亮回归

标题遮线背景须按已有绑定与 `data-cluster-id` 精确关联，作为仅填充的伴随图元同步主体选中色，保存并恢复原填充及优先级；不移除遮线背景、不按标题名称匹配，也不为背景增加描边或滤镜。

默认及筛选重排共用此路径，自动覆盖全部真实集合的选择、缩放与恢复。使用真实包装及全部调度绑定断言实际填充、描边和滤镜变化，不以选择类或详情代替高亮检查。

## 图例状态

默认视图与实际筛选结果的 `legendKinds` 随成功呈现一并更新，隐藏 marker 不作为对象；零结果保持右栏并显示图例空状态，失败及迟到结果不替换已显示内容。

## 按需资源、缓存与 Worker

浏览器只拿必要共享目录与目标视图，不重复内嵌全部图及模型；缓存最多八张，加载失败与迟到结果不得破坏选择、图例或历史。

默认 SVG、完整对象图和逐视图元数据从本地服务按需读取，Schedule 筛选使用内嵌 Graphviz WASM Worker。单关系图首次选择才加载本地单模块，导入前核对同源、SHA-256 和字节数；核对元数据与完整 SVG 缓存隔离、共享模块加载、取消、失败重试、过时响应及资源回收。两类原生绘图均不加载 CDN、额外字体或 WASM；分发运行库时保留对应许可证与来源说明。静态 SVG 身份须严格校验，临时原生 DOM 身份不得替换对象业务身份。
