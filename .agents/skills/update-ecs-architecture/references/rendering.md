# 对象绘图、几何与图例

在对象可见投影、Mermaid 编译、样式、布局或图例生成维护前读取；语义身份归[对象模型](object-model.md)，Graphviz 调度布局归[调度](schedules.md#graphviz-呈现与语义边界)，实际目测归[视觉验收](visual-validation.md)。

## 对象可见投影

按[对象专属图](../../../../docs/diagrams/README.md#对象专属图)核对每个生产对象恰好一张完整导出图：中心唯一，`Plugin`／`PluginGroup` 中心只保留单卡与零可见边；其余对象包含全部直接邻居及中心的全部入出边，不递归扩展、不加入邻居之间的边。中心 `kind=Entity` 时再过滤全部 Component 及触及它们的边，并按剩余端点重算可见邻居；无可见关系时保留中心单卡。全局对象、关系目录及其他对象图的插件关系不删减。

默认浏览与完整导出分别按[高密度对象关系](../../../../docs/diagrams/README.md#高密度对象关系)核对。达到阈值时默认完整关系列表，选择只投影该条原关系和去重后的真实显示端点；原始端点与证据保留，不复制自环节点或预先生成所有关系对。单关系图复用共享纯核心、原生 Mermaid 候选、安全及严格文字／几何检查；临时 DOM 编译身份与业务身份分开。完整图仍保留全部一跳关系，不能通过列表搜索删改导出或结构事实。

组件与实体模板的装配归属按[关系与操作证据](object-model.md#关系与操作证据)核对。

## 语义样式与原生布局

按[视觉规范](../../../../docs/diagrams/README.md#节点与连线视觉规范)与[Mermaid 布局](../../../../docs/diagrams/README.md#mermaid-布局与连线)生成对象图。分类目录维护语义 kind，样式模块维护形状和配色，不能相互推断。保留真实关系、相反读写方向、有向环和原生布局；不可见布局约束不增加业务身份或执行关系。

对象、单关系及 Schedule 的可见标题共用短名格式化，在原生布局前应用；函数和方法只显示函数名，类型保留递归短化的泛型结构。完整名称、稳定身份和原始 DOT 不变，同短名对象不合并。几何与文字校验核对完整短标题和摘要，不能仍以全路径为可见标题要求。

## 严格几何与文字检查

全部 Mermaid 原生候选执行同一严格几何检查，核对真实轮廓、路径、源端接触、目标箭头、标签背景及遮挡，不能只检查包围框。缓存也须核对实际可见文字，特别是长泛型及转义字符；只有文字损坏时才扩大原生自动换行宽度重编，随后执行全部检查。

编译并发参数见[生成与校验命令](../../../../docs/diagrams/README.md#生成与校验命令)，静态截图的单写者与恢复规则见[SVG 证据命令](../../../../docs/diagrams/README.md#svg-证据命令)。提高并发前核对可用内存及其他浏览器任务；稠密图的单页开销可能明显高于单卡，不能按核心数保证所有页面都能同时驻留。自动检查稳定并冻结产物后再安排[实际观察](visual-validation.md#委派观察与-v2-证据命令)。

## 原生参数回退边界

默认 `padding=16`；仅其他检查全部通过而源端接触失败时可试 `padding=4`，随后重跑完整检查。不得手工移动连线、箭头或标签、删边或放宽容差。

## Graphviz 图例生成

维护 `guideSamples.schedule` 时使用锁定 Graphviz 与现有调度配色生成系统、圆角集合、上下文、依赖箭头及无箭头成员线样例，不能借用形状不同的 Mermaid 图例。呈现复用对象图例的透明底、无字横向样例与对齐，英文类别仅在右侧；固定样例尺寸在布局前应用，原生几何四侧各留 `5px`。图例编译与浏览器分类分离，不把 Node 几何依赖打入离线筛选运行时，也不修改正式调度主题。校验背景透明、没有可见文字及节点横向比例。

校验原生轮廓、样式、箭头、可访问标签、跨样例唯一 ID 及 SVG 安全，不恢复导出元数据栏。

图例随视图成功呈现更新的规则见[查看器图例状态](viewer.md#图例状态)。
