# 视觉证据、浏览器验收与交付

在自动检查稳定、分发目测任务、恢复证据或浏览器验收前读取；角色模型与单写者归[维护流程](workflow.md#角色与默认模型)，模型和几何检查不能替代本参考要求的实际观察。

## 冻结验收输入

自动检查稳定后，冻结目测与 HTTP 验收使用的输入提交、未提交变更指纹及产物哈希，再分发任务。验收期间若输入改变，重跑受影响的自动检查并重新冻结，不能把不同版本的通过结果拼作最终验收。

## 默认逐图与用户免除

按[架构图视觉检查](../../../../docs/testing/README.md#架构图视觉检查)实际查看最终 HTML 与独立 SVG。用户明确免除逐图检查时，停止逐图栅格化、联系表和目测，不据此阻止交付或再次请求确认；保留编译、模型、几何、产物及交互回归检查，并如实记录逐图目测已按要求跳过。

## 有效证据复用与抽样范围

未免除时，先以当前 SVG 的路径、图身份、完整 SHA-256 及图片证据查找有效通过记录；即使相对基线变化也优先复用匹配记录，只有缺少有效当前记录的图进入待目测清单。逐图检查为默认，默认列出全部其余待检项；仅用户明确授权才指定抽样数量、种子及范围，不默认 100 张，也不沿用其他任务的样本数量。变化交互的实际浏览器验证与静态检查分别记录。

## 委派观察与 v2 证据命令

SVG 逐图目测及用户明确限定范围的抽样目测必须委派子代理，主代理只负责统筹、汇总和证据复核。

按[SVG 证据命令](../../../../docs/diagrams/README.md#svg-证据命令)执行 `visual plan/render/record/bind`，待检清单按[有效证据与抽样规则](#有效证据复用与抽样范围)确定。

冻结后才渲染，零待检不启动浏览器，截图仍为待检；子代理实际观察对应全部预览与分块后显式记录检查者、时间、结论及具体备注。

## 索引、提交绑定与旧数据迁移 TODO

索引默认在主检出 `tmp/ecs-architecture/visual-checks/index-v2.json`，提交绑定独立追加，不改历史观察。旧格式数据迁移尚未实现，不隐式读取或计作新工具复用，可能重复检查；保留原索引和截图。对应 PR 保存完整清单、证据及实际覆盖范围。

## HTTP、协议拒绝与离线分发

生成和校验完成后，自动预览先按[本地自动预览](../../../../docs/diagrams/README.md#本地自动预览)启动本工作区的开发服务，再请求浏览器访问服务输出的 `http://127.0.0.1:<端口>/pages/ecs-architecture.html`，显式传入工作区根目录。HTTP 是预先选择的默认入口，不作为浏览器策略拒绝后的替代路径；拒绝后停止该目标的浏览器验收并记录缺项。本地 HTTP 与断网目录分发检查分别记录。

## SVG 实际观察项

检查完整文字、原生箭头、裁切与遮挡，Schedule 背景与画布同为 `#F6F8FB`，集合标题不被连线遮挡；对象图另查中心、单卡或一跳邻居、组件投影索引、语义样式、详情及源码。

## 浏览器交互与布局验收

实际验证顶栏选图与对象搜索浮层、Schedule 默认图例右栏与左键选择详情、插件单卡、严格筛选与离线重新布局、旧链接、别名候选、返回与历史、平移缩放、面板、焦点、复制及工作区配置。桌面浏览器缩窄窗口检查布局，不要求手机或真实触屏验收。

实际检查[空筛选恢复与同源资源边界](schedules.md#筛选投影与中间模型)及[按需资源](viewer.md#按需资源缓存与-worker)。静态编译或 Node WASM 成功不代表浏览器验收或 VS Code 实际打开。

## 交付分类与未验证项

分别报告真实导出／导入、代码与模型检查、SVG 目测或用户免除的范围、HTML 浏览器及协议验收。列出具体变化、完成范围与未验证项；执行记录放对应 Issue／PR，长期文档只保留可复用指导。临时材料放根 tmp，不启动或操作游戏，不使用编译浏览器绕过本地文档访问限制。
