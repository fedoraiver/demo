# 视觉证据、浏览器验收与交付

在自动检查稳定、分发目测任务或恢复证据前读取；角色模型与单写者归[维护流程](workflow.md#角色与默认模型)。HTTP 浏览器与 VS Code 协议验收的停用范围见[验证参考](../../../../docs/testing/README.md#架构图视觉检查)。

## 冻结验收输入

用户明确启用 SVG 目测或重新要求 HTTP／VS Code 验收时，在自动检查稳定后冻结所用的输入提交、未提交变更指纹及产物哈希，再分发任务。验收期间若输入改变，重跑受影响的自动检查并重新冻结，不能把不同版本的通过结果拼作最终验收。

## 默认范围与用户启用

本项目默认不执行 SVG 视觉验证，包括逐图或抽样目测、用于视觉验收的栅格化截图和联系表。只有用户明确要求时才启用，不主动请求抽样或豁免确认。默认执行编译、模型、文字与几何、产物及交互自动回归，包括隔离夹具的样式与有效透明度测量；这些结果不计为人工目测。交付记录 SVG 视觉验证已跳过，不因缺少目测记录阻止交付，也不把跳过计为目测通过。

HTTP 浏览器与 VS Code 协议验收不再安排，不启动正式页面或外部编辑器进行验收，也不主动请求重新启用。维护状态记录为 `not-required`，交付不列为待办、未验证缺项或阻断条件；保留已有历史记录。相关 URI、资源加载及交互自动回归继续执行。以下正式页面和协议步骤仅供用户明确重新要求时使用。

## 有效证据复用与抽样范围

启用 SVG 视觉验证时，先以当前 SVG 的路径、图身份、完整 SHA-256 及图片证据查找有效通过记录；即使相对基线变化也优先复用匹配记录，只有缺少有效当前记录的图进入待目测清单。用户未限定抽样时覆盖全部其余待检项；本次抽样数量、种子及范围须由用户明确授权。SVG 目测不自动启用 HTTP 或协议验收。

## 委派观察与 v2 证据命令

用户明确启用的 SVG 逐图目测及限定范围的抽样目测必须委派子代理，主代理只负责统筹、汇总和证据复核。

按[SVG 证据命令](../../../../docs/diagrams/README.md#svg-证据命令)调用 [Skill 视觉证据模块](../scripts/maintenance-visual.mjs)的 `visual plan/render/record/bind`，待检清单按[有效证据与抽样规则](#有效证据复用与抽样范围)确定。[静态栅格化模块](../scripts/maintenance-visual-render.mjs)使用图包的锁定依赖，不另行安装浏览器包。

冻结后才渲染，零待检不启动浏览器，截图仍为待检；子代理实际观察对应全部预览与分块后显式记录检查者、时间、结论及具体备注。

## 索引与提交绑定

`schemaVersion: 2` 索引默认在主检出 `tmp/ecs-architecture/visual-checks/index-v2.json`，记录通过身份和哈希验证后才可复用。保留索引和截图；提交绑定独立追加，不改历史观察。对应 PR 保存完整清单、证据及实际覆盖范围。

## HTTP、协议拒绝与离线分发

仅在用户明确重新要求 HTTP 验收时，生成和校验完成后按[本地自动预览](../../../../docs/diagrams/README.md#本地自动预览)启动本工作区的开发服务，再请求浏览器访问服务输出的 `http://127.0.0.1:<端口>/pages/ecs-architecture.html`，显式传入工作区根目录。HTTP 不作为浏览器策略拒绝后的替代路径；拒绝后停止该目标的浏览器验收。本地 HTTP 与断网目录分发检查分别记录。

目标被拒绝后不换端口、协议、浏览器或自动化入口重试该目标。隔离原生编译夹具不得加载被拒页面、访问其 URL 或调用外部协议；夹具结果只能证明对应自动回归，不能充当正式页面验收。

## SVG 实际观察项

本节仅在用户明确启用 SVG 视觉验证时执行。

检查完整文字、原生箭头、裁切与遮挡，Schedule 背景与画布同为 `#F6F8FB`，集合标题不被连线遮挡；对象图另查中心、单卡或一跳邻居、组件投影索引、语义样式、详情及源码。

高密度对象同时记录完整导出和默认阅读路径。完整导出保留全部关系用于整体参考，逐图核对文字、裁切、真实节点与关系及原生几何；细读使用完整目录和单关系图，另核对真实端点、方向、标签和证据。原生关系编译夹具不等于正式页面交互验收。

## 浏览器交互与布局验收

本节仅在用户明确重新要求对应的 HTTP 或 VS Code 验收时执行。

实际验证顶栏选图与对象搜索浮层、Schedule 默认图例右栏与左键选择详情、插件单卡、严格筛选与离线重新布局、兼容链接、别名候选、返回与历史、平移缩放、面板、焦点、复制及工作区配置。桌面浏览器缩窄窗口检查布局，不要求手机或真实触屏验收。

高密度对象实际验证完整目录、关键词与空结果、任意关系选择、两端卡片和关系详情、清高亮、返回目录、显式全图和下载，以及搜索／滚动／视角的历史恢复。检查首次选择的本地模块加载、失败重试、快速切换和离屏编译容器清理；完整名称在窄画布与目录中保持可读。

实际检查[空筛选恢复与同源资源边界](schedules.md#筛选投影与中间模型)及[按需资源](viewer.md#按需资源缓存与-worker)。VS Code 验收从正式页面分别点击项目与依赖源码入口，确认实际打开的文件、行和列；URI 正确、协议已注册或请求已发出均不证明打开成功。访问受限时保留人工验收项，不以静态编译、Node WASM 或夹具结果代替。

## 交付分类与未验证项

报告真实导出／导入、代码与模型检查及 SVG 视觉验证的跳过或明确启用范围；HTTP 和 VS Code 验收记录为不需要，不列入未完成事项。只有用户明确重新启用后，才报告对应的实际验收结果。列出具体变化及自动检查范围；执行记录放对应 Issue／PR，长期文档只保留可复用指导。临时材料放根 tmp，不启动或操作游戏，不使用编译浏览器绕过本地文档访问限制。
