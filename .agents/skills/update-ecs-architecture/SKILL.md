## Schedule 导出与导入

按[调度快照](../../../docs/diagrams/README.md#调度快照)核对覆盖和边界。导出复用真实应用装配，在插件就绪并完成 `finish` 后、`cleanup` 前，记录主应用及可访问子应用中的全部已注册 Schedule。应用与 Schedule 共同标识图，不按标签名称合并不同应用的调度。

需要更新真实调度快照时，Agent 直接运行专用导出命令：

```powershell
cargo run --locked --features debugdump -- --dump-schedules tmp/debugdump
```

该专用导出允许 Agent 执行，不进入游戏循环、不执行 Startup，但完整装配可能初始化 GPU、音频设备及资产。执行边界见[验证参考](../../../docs/testing/README.md#agent-验证边界)；不得省略 `--dump-schedules` 或改为启动、操作游戏。导出失败时完成独立工作并明确缺项，不用测试夹具或旧系统图冒充真实结果。

检查导出清单的应用、Schedule、稳定文件身份、依赖版本、内容哈希及源码指纹。缺失、冲突或过期输入必须使导入失败。正式清单、DOT、SVG 和 HTML 一起保留，源码指纹匹配时可从正式 DOT 离线重建。

Graphviz 由锁定的 `@viz-js/viz` 生成默认 SVG，并在浏览器离线 Worker 中按需重排筛选后的 Schedule。呈现样式在布局前应用，系统、集合和依赖线复用对象样式，位置与路径仍由 Graphviz 产生；不套用 Mermaid 的身份或严格走线检查，不手工接线、改箭头或补画关系。它表达注册快照，不表示条件成立、系统实际执行、后续动态注册或 Observer 触发关系，也不拼接跨 Schedule 总序。

维护[调度筛选](../../../docs/diagrams/README.md#调度筛选与重新布局)时，核对包含／排除下拉按来源 Plugin 组多选、目录与完整路径的对应、未知来源及无当前系统的已选组；不把定义路径当作实际注册 Plugin 的证据。勾选、取消、批量选择和清空立即生效，搜索仅缩小选项范围，集合名不参与筛选；核对多组并集、空包含与排除优先，以及旧完整名称、旧文本条件的兼容和取消。筛选保留命中系统、必要祖先集合与 marker，以及两端仍存在的原边，不加入未命中系统邻居或跨删除节点补边；原生上下文端点按该节规则保留，不补造名称或计入系统数。空筛选直接恢复默认 SVG，不初始化 WASM；零命中与失败明确反馈。保留原始 DOT、来源哈希及节点身份，核对中间模型的边、有效属性和集合层级，以及分组元数据与来源的对应；不把限定的 debugdump 转换器当作通用 DOT 无损解析器。

## 对象模型与源码核对

对象清单继续维护系统、Observer、实体、组件、资源、消息、访问和注册事实；删除旧系统页不删除对象目录依赖的共享数据。核对真实声明、注册、SystemSet、运行条件、显式顺序与延迟命令可见时机，区分 Component、Resource、Local、NonSend、QueryData、SystemParam、helper 及普通实体引用。数据访问、插件装配和 Schedule 执行顺序分别表达。

保留稳定节点、关系、原实体投影和各次注册身份；别名只连接同一声明，不按显示名、类型、函数或 canonical Entity 合并对象。复合消息与泛型聚合按真实类型拆分，旧聚合只保留候选映射，不任选一个对象。

真实快照中同函数的不同注册保留独立实例；维护清单的测试 scope 不改变已导出的注册事实。核对有条件的 Startup 回退与 OnEnter 入口，不因用途相同而合并身份，也不凭仅存在清单中的测试注册补造运行快照。

按[对象专属图](../../../docs/diagrams/README.md#对象专属图)核对每个生产对象恰好一图：中心唯一，`Plugin`／`PluginGroup` 中心只保留单卡与零可见边；其余对象包含全部直接邻居及中心的全部入出边，不递归扩展、不加入邻居之间的边。中心 `kind=Entity` 时再过滤全部 Component 及触及它们的边，并按剩余端点重算可见邻居；无可见关系时保留中心单卡。全局对象、关系目录及其他对象图的插件关系不删减。组件投影归属来自 `model.entities[*].components`，不按名称或 ID 前缀猜测；完整索引保留在模型中，右栏不展示组件清单。

统一关系包含实体挂载、系统访问与组件操作、消息与事件、实体引用与关系、注册、集合成员及显式顺序。逐条区分字段读取、可变访问、实际修改、添加、移除、存在过滤与反射。`With`／`Without`／`Has`、Option 查询或存在判断不自动等于字段读取，`writes` 不证明插入或移除。追踪 helper、World 闭包、Commands 和关系 hook 的真实条件、生效时机及证据；helper 不冒充注册系统，未核实操作保留缺口。

按[源码范围](../../../docs/diagrams/README.md#源码范围)逐类核对 `sourceEntries`：Component 提供真实定义及对应实体投影的创建／装配与销毁，Entity 提供创建与销毁，System／Observer 提供定义及该对象对应注册；其他类别依规范表。组件的后续插入、移除与实体销毁须核对该投影的证据，自动生命周期提供实际配置与实现，不把可变访问或普通写入推断为创建、销毁。原 `source` 不自动成为定义入口；必要入口缺证据时写入 `sourceGaps`，不得用普通使用处或虚构实现补齐。操作边定位实际操作、参数或配置。

项目声明通过定位模块核对；依赖定义使用锁定包身份、泛型实参及 `cargo metadata --locked --offline` 获取的真实源码。核对别名、宏声明、同名二维／三维类型、声明唯一性、行列、目录边界、来源角色与完整快照，不硬写本机 Cargo 根目录，不让工作区配置覆盖依赖根。

缺失的访问类型按[类型用途目录](../../../docs/diagrams/src/schedule-type-purposes.mjs)补具体中文职责，Local 按函数与参数槽核对状态用途；原始文档、字段与使用场景不能替代职责说明。关联类型未展开时保留自身身份及缺口，不按末段短名借用其他声明。

系统用途按[系统用途目录](../../../docs/diagrams/src/schedule-system-purposes.mjs)核对实际函数体及必要 helper，分别维护图内短句和完整说明；保留条件、主要输入输出及清理职责，不用函数名翻译、参数枚举或通用 API 模板替代。正式构建缺少已核对用途时必须失败。

命名集合按[集合用途目录](../../../docs/diagrams/src/schedule-set-purposes.mjs)核对声明、枚举项文档和配置，不能只重复集合名称；空阶段保留扩展约定，匿名集合只说明已核实的共同运行条件与成员事实，具体配置未定位时保留缺口。

按[函数体操作目录](../../../docs/diagrams/src/schedule-body-operations.mjs)补全已核实的结构操作、消息输出及显式 World 访问，检查调用片段、类型依据、主／子世界范围与 Commands 延迟时机。只追踪明确指定的 helper，保留真实调用方和操作两处证据；不把容器方法、可变借用、动态回调或销毁实体推断为某个固定组件的插入、修改或移除。

保留业务系统 → tracing producer，再分 File worker → 会话文件与 Console worker 的日志拓扑。文件保持 External I/O 身份及真实创建入口，不增设没有依据的队列、stderr 或退出关系。

## 对象绘图与页面交互

按[视觉规范](../../../docs/diagrams/README.md#节点与连线视觉规范)与[Mermaid 布局](../../../docs/diagrams/README.md#mermaid-布局与连线)生成对象图。分类目录维护语义 kind，样式模块维护形状和配色，不能相互推断。保留真实关系、相反读写方向、有向环和原生布局；不可见布局约束不增加业务身份或执行关系。

全部 Mermaid 原生候选执行同一严格几何检查，核对真实轮廓、路径、源端接触、目标箭头、标签背景及遮挡，不能只检查包围框。缓存也须核对实际可见文字，特别是长泛型及转义字符；只有文字损坏时才扩大原生自动换行宽度重编，随后执行全部检查。默认 `padding=16`；仅其他检查全部通过而源端接触失败时可试 `padding=4`，随后重跑完整检查。不得手工移动连线、箭头或标签、删边或放宽容差。

卡片右栏按[节点详情](../../../docs/diagrams/README.md#节点详情)仅显示名称、完整 `description`、符合现有条件的“打开对象关系图”及源码位置。删除归属、注册参数、访问、Query、字段、组件清单、函数体操作明细及附带源码和清除选择按钮，不因显示范围删减共享数据。未选中时的图例及连线详情保持各自内容；卡片通过画布空白清除，连线详情的清除按钮保留。同函数其他注册继续拥有各自身份和可搜索对象图。源码编辑器、复制反馈、工作区与依赖定位遵守[源码定位验证](../../../docs/testing/README.md#架构图源码定位验证)。

查看器使用顶部选图，不保留左侧导航；Schedule 按应用分组，默认主应用 `Update`，缺失时选首个非空调度。Schedule 始终显示右侧说明栏，未选择时为当前图的英文 Graphviz 图例；鼠标左键单击系统、集合边框或标题、可见上下文卡片后显示可调整的右侧详情，并提供对象关系图入口，清除后回图例，不收起面板或桌面分隔条。左键拖动继续平移，左键单击 SVG 内外主画布空白清除选择，集合填充背景仍选中集合，调度依赖线、箭头和标签保持选择；右键、菜单键与 Shift+F10 使用浏览器菜单，Enter／Space 查看聚焦对象。交互只附加到页面 DOM，不改独立调度 SVG、DOT 或原模型。核对按应用、Schedule、原始图元身份及 DOT 哈希绑定，不按短名合并泛型、重复注册或匿名集合；集合成员须覆盖原成员边及 marker 传递，同步点和缺失目标保留真实类别。缺失对象依据锁定源码补完整说明、访问及一跳关系，不能以通用占位或基础单卡替代。对象图保留选择、详情、图例、源码及可调整面板；全局对象搜索和旧聚合候选显示在顶栏浮层，不占用详情栏。插件菜单不单列“其他插件”，`WorldInspectorPlugin` 与 `EguiPlugin` 相邻；未列入菜单的对象仍可搜索或从旧链接访问，并显示为当前对象。菜单入口不改变真实装配或调度筛选目录。两类图均支持平移、缩放、适合窗口及历史恢复；Plugin 菜单、搜索、对象图及普通链接入口进入对应 Plugin／PluginGroup 单卡图并默认未选中，显示 Mermaid 图例；有效显式 `node`、卡片激活和选中历史仍显示说明。清除恢复图例，不通过中心兜底重新选中插件；其他对象默认选择不改。

核对 `schedule`、重复的 `scheduleIncludePlugin`／`scheduleExcludePlugin`、兼容的系统与文本筛选参数、`scheduleNode`、`object`、`node` 及来源上下文；条件实际变化立即更新 URL 并新增一次历史，批量操作一次、相同条件零次。实时筛选与异步完成保留下拉、搜索词、滚动位置、焦点及旧条件候选，不以完整导航重置筛选控件。视角只关联实际成功呈现的条件；未完成或失败的历史条件返回时重排并适合窗口。核对选择和空白清除均只替换当前历史、打开对象图后返回调度选择与视角；成功筛选仅清除已不可见的选择，失败保留成功画面与详情。切 Schedule 后仍可取消没有本图系统的已选组及旧条件；检查逐项选择、批量选择当前搜索结果中有系统的组、单栏及全部清空。旧总览进入默认调度，旧插件链接的有效节点进入精确对象，无节点时进入插件对象，旧 component 与聚合候选继续迁移。保留 workspace、其他参数和片段，兼容使用历史替换。焦点、面板、搜索、选择恢复及复制反馈按图的说明与验证参考检查，不让选择或 `paint` 抢其他控件焦点。

全部 SVG 的卡片及对象图连线统一鼠标左键选择；未拖动且释放位移不超过 `6px` 时按释放坐标命中，合成点击不得重复激活。触摸点按不选择，平移缩放和页面控件保留。鼠标命中须区分可选对象、非交互图元和真正画布背景，不能把所有未选中命中都当空白；画布外、空命中和控件不处理。复用清除路径，保留视角、搜索文本／历史查询、筛选及对象页的返回来源 `scheduleNode`；历史恢复和筛选迟到结果不得使已清高亮复活。调度图穿过 Graphviz 的 `g`／`a` 包装寻找当前对象轮廓，遇到子对象、边和标题层时停止；复用对象图选中填充、增粗与蓝色外圈，不给文字或嵌套系统施加集合滤镜。集合标题共指主体、无独立 Tab 停靠或选中框。标题遮线背景须按已有绑定与 `data-cluster-id` 精确关联，作为仅填充的伴随图元同步主体选中色，保存并恢复原填充及优先级；不移除遮线背景、不按标题名称匹配，也不为背景增加描边或滤镜。默认及筛选重排共用此路径，自动覆盖全部真实集合的选择、缩放与恢复。使用真实包装及全部调度绑定断言实际填充、描边和滤镜变化，不以选择类或详情代替高亮检查。

## 生成与校验

包根仅保留说明、配置和 build／check／serve 薄入口；实现、人工目录、测试及许可证分别归入 `src/`、`catalog/`、`tests/`、`licenses/`。生成文件在 `generated/` 内按页面、数据、对象／调度／图例 SVG、DOT 和 Mermaid 分类。路径由共享模块管理，新格式夹具使用相同目录策略，旧格式平铺夹具仅保留兼容验证；移动文件后更新引用、文件属性和清理清单，保持原始 SVG／DOT／Mermaid 字节与身份。浏览器只拿必要共享目录与目标视图，不重复内嵌全部图及模型；缓存最多八张，加载失败与迟到结果不得破坏选择、图例或历史。

维护 `guideSamples.schedule` 时使用锁定 Graphviz 与现有调度配色生成系统、圆角集合、上下文、依赖箭头及无箭头成员线样例，不能借用形状不同的 Mermaid 图例。呈现复用对象图例的透明底、无字横向样例与对齐，英文类别仅在右侧；固定样例尺寸在布局前应用，原生几何四侧各留 `5px`。图例编译与浏览器分类分离，不把 Node 几何依赖打入离线筛选运行时，也不修改正式调度主题。校验背景透明、没有可见文字及节点横向比例。默认视图与实际筛选结果的 `legendKinds` 随成功呈现一并更新，隐藏 marker 不作为对象；零结果保持右栏并显示图例空状态，失败及迟到结果不替换已显示内容。校验原生轮廓、样式、箭头、可访问标签、跨样例唯一 ID 及 SVG 安全，不恢复导出元数据栏。

已有有效正式 DOT 时直接重建；Rust 源码或锁定依赖变化时先运行上述专用命令生成新的真实导出。从仓库根依次运行，失败修复后重试：

```text
npm ci --prefix docs/diagrams
node docs/diagrams/build-ecs.mjs --debugdump tmp/debugdump
node docs/diagrams/check-ecs.mjs
node --test docs/diagrams/tests/*.test.mjs
```

已有有效正式调度清单与 DOT 时，可省略 `--debugdump`；仅查看器、筛选模型或样式变化不要求重新运行应用，也不触发 Rust 检查。Node.js、渲染器及编译要求以锁定依赖为准；Mermaid Chromium 只用于文档编译。默认 SVG、对象图和逐视图元数据从本地服务按需读取，Schedule 筛选使用内嵌 Graphviz WASM Worker，仅允许同源文档资源请求，不加载 CDN、额外字体或 WASM。核对 Worker 复用、取消、过时响应、SVG 安全检查与失败时的静态图恢复；分发内嵌运行库时保留对应许可证与来源说明。

动态产物清单包含 Schedule DOT／默认 SVG、object Mermaid／SVG、独立图例 SVG，以及两份 HTML、外部索引／逐视图数据、完整校验模型和源码快照；旧总览、插件及基础设施系统图不残留。筛选结果不覆盖正式产物。校验器按 engine 分派：Graphviz 核对清单、来源、尺寸与输入输出对应；Mermaid object 保留原身份、单卡／一跳可见投影、源码与几何检查。自动审计不代替源码核对，也不保证发现全部遗漏的 Rust 行为。

## 视觉检查与交付
