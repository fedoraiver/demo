# 文档检查与改进

在当前项目工作区检查文档，保留后续使用与维护需要的信息，删除无用表达。默认检查并修正整个项目的维护文档；用户指定文件、目录或仅检查时，以用户的范围和动作要求为准。

先按 [review-docs 工具说明](references/tooling.md) 初始化会话，再运行检查、记录覆盖与证据并生成报告。脚本冻结初始基线，发现清单，检查链接、锚点、入链、Skill 结构和差异，验证分工申报与证据；代理处理异常和需要判断的内容，不为每次机械检查单独派发模型。初始基线与当前内容指纹分开；输入变化后重新确认受影响证据，不修改历史记录。工具不代替事实审查或独立终审。

按工作阶段读取详细规则：

- 确定工作区、范围、文档归属及依据时，读取[范围与依据](references/scope.md)。
- 分配职责、派发或独立复审时，读取[分工与派发](references/delegation.md)；同一文件始终只有一个编辑者，独立终审须由未参与编辑者承担。
- 核对事实、决定保留或修订内容时，读取[审查与取舍](references/review-rules.md)。默认修正依据明确的问题；仅检查时不修改文件。文档任务不改产品行为，不自行增加项目约束。
- 选择检查、复核增量和交付时，读取[验证与交付](references/validation.md)。禁止启动或操作游戏，不自动提交。
