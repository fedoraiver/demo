# 使用说明

本文说明当前演示内容、操作、设置、资源准备和问题反馈。玩法探索与确认状态见 [游戏设计](game-design.md)。

运行方式见 [README](../README.md#运行)，开发构建与发布说明见 [开发规范](development.md#构建与调试)，实际操作检查见 [游戏手动验收](testing/game-acceptance.md)。

## 当前内容

当前 demo 提供英文主菜单、暂停菜单、设置、操作说明和事件音效。`Start Game` 加载 Courier Island 海岛、蓝色制服角色、四名 NPC，以及普通纸箱、易碎纸箱和木箱。

人物可在第一人称视角下移动、跳跃和拿放箱体。人物和物品受重力与碰撞影响；玩家或可搬物品落水后回到各自出生点。

## 菜单与占位功能

启动后进入英文主菜单。`Start Game` 进入演示场景，`Settings` 打开设置，`How to Play` 查看当前操作，`Quit` 正常退出。游戏内按 Esc 打开暂停菜单；`Resume` 或再次按 Esc 恢复，`Settings` 和 `How to Play` 返回后仍保持暂停，`Back to Main Menu` 清理当前玩法场景。再次选择 `Start Game` 会从初始场景开始。

鼠标可点击可用按钮；上／下方向键移动焦点，Enter 确认，Esc 返回，设置字段用左／右方向键或行内箭头调整。菜单也支持手柄方向键、南侧按钮确认、东侧按钮或 Start 返回。

可交互按钮在鼠标进入时高亮，离开后恢复普通纸色。键盘或手柄导航时显示当前焦点；实际移动鼠标可切回鼠标操作。当前分类和 `Apply` 不常驻高亮，帮助页的黄色编号块仅作装饰。

页面中的灰色 `Coming Soon` 行是不可操作的占位，键盘导航会跳过；当前菜单内容如下：

| 页面 | 可用功能 | `Coming Soon` 占位 |
| --- | --- | --- |
| 主菜单 | Start Game、Settings、How to Play、Quit | Continue、Multiplayer |
| Graphics | Frame Rate Limit | Window Mode、Resolution、VSync、Shadow Quality、Anti-Aliasing、View Distance |
| Audio | Master Volume、SFX Volume、UI Volume、Test SFX | Music Volume |
| Controls | Mouse Sensitivity、Invert Camera Y | Rebind Keys |
| Accessibility | 暂无可调辅助功能 | UI Scale、Camera Shake |

Windows 与 macOS 的游戏内容区保持 16:9，初始为 `1280×720`，可拖动边缘或角等比例缩放；正常最小尺寸为 `960×540`。最大化使用屏幕工作区内最大的 16:9 窗口；macOS 禁用系统全屏与全屏平铺。

工作区小于最小尺寸时，优先保持窗口完整可见，菜单布局可能不完整。未适配原生比例约束的平台使用固定尺寸窗口；适配安装失败也禁用缩放并记录错误。

主菜单、暂停菜单和操作说明完整展示，不随滚轮或方向键滚动。设置中只有右侧纸色面板的标题、项目、说明与保存提示可以滚动；左侧分类、底部 `Restore Defaults / Apply / Back` 和页脚固定。

面板内容超出可用高度时显示滚动条。可在面板内使用滚轮、拖动滑块或点击轨道滚动；键盘焦点会自动滚入可视区域。内容无需滚动时隐藏滚动条，面板外的滚轮不移动页面。

## 美术与字体准备

发布包需携带完整的 [assets/](../assets/)，保持原有路径结构。该目录包含地图、独立角色与物品模型、主菜单舞台资源、字体和声音；只复制可执行文件无法完整运行演示。

制作源、导出与预览方法见 [海岛美术资产](../art/ASSET_GUIDE.md) 和 [道具美术资产](../art/items/README.md)。装备、机械和魔法道具库供美术制作与后续接入使用，当前游戏不提供这些道具的能力。

菜单使用 Lilita One 与 Atkinson Hyperlegible 字体，来源和许可证见 [字体来源](../assets/ui/fonts/SOURCES.md)。资源加载失败时检查本次 [会话日志](#会话日志) 中的文件路径；主菜单舞台的错误使用 `Menu asset failed to load` 消息。

## 当前操作

| 操作 | 行为 |
| --- | --- |
| 鼠标移动 | 直接控制镜头水平朝向和上下俯仰，无需按住右键；人物水平朝向随视角变化。 |
| W / S | 沿当前视角的水平前方加速前进或后退，松键后较快减速，不因后退改变朝向。 |
| A / D | 沿当前视角的水平左右方向加速横移，不改变朝向；斜向输入不会提高目标速度。 |
| 空格 | 地面起跳并落回地面；持续按住不会反复跳跃，空中不能再次起跳。 |
| E | 拿起范围内最近且无遮挡的纸箱或木箱，安全对齐到手前；持有时再次按下，从当前位置释放并保留速度，自然掉落。 |
| Esc | 打开暂停菜单，显示光标并冻结当前玩法；在暂停菜单再次按下恢复。 |
| F3 | 调试时释放光标，保持游戏运行，以操作世界检查器。 |
| 左键点击检查器之外的游戏区域 | 恢复鼠标控制；窗口失焦会自动释放，重新获得焦点后也需点击恢复。点击检查器不会捕获鼠标。 |

游戏使用第一人称，镜头位于角色脚底上方 `1.65` 米，进入时平视，俯仰范围为 `-85°..85°`；隐藏自己的角色模型，持有物品仍可见。建筑保持原有外观。

暂停时停用玩法输入；恢复后重新捕获鼠标，忽略自由光标阶段积累的位移。

角色会受到固定结构阻挡，能够推动自由箱体，也会受到外力影响。拿起物品并安全对齐后，箱体随人物稳定移动与转向。直走时手持箱碰到 NPC、建筑或其他箱体，会使人物与箱体一起停下并保持持握；转身路径被阻挡时，箱体在转动前的安全位置自动释放，视角继续转动。

手动和自动释放均保留实际位置与速度，箱体可继续滑动、翻滚和落地。人物可持箱移动和跳跃。60／120 FPS 的检查方法见 [游戏手动验收](testing/game-acceptance.md)。

## 海岛与美术资源

四名 NPC 位于固定位置，其身体会阻挡玩家、自由箱体和手持箱体，NPC 不会被推动。普通纸箱和易碎纸箱位于出生点前方，三只木箱位于物流总站内的柜台与货架之间；柜台、货架上的其他纸箱和商店摆件属于静态装饰。

主角具有站立、四方向行走、起跳、下落和落地动作，以及对应的持箱姿态。转向、斜向移动与拿放时动作连续过渡，持箱行走保留搬运上身姿态；空中拿放不重置动作进度。动作制作见 [海岛美术资产](../art/ASSET_GUIDE.md#比例与导入)，运行同步机制见 [主角动画与落水恢复](architecture.md#主角动画与落水恢复)。

人物可沿三个商铺及两栋住宅的入口台阶走上平台；海水、叶片和草不能充当地面。人物落水后解除持物并回到出生点，清除速度和待执行的跳跃、拿放请求；可搬物品落水后回到自己的初始位置。

加载期间等待地图与碰撞准备完成，再出现玩家和可搬物品。资源加载失败时，检查资源是否完整并提供对应日志。模型显示、通行、动作与恢复行为的检查见 [游戏手动验收](testing/game-acceptance.md)。

## 世界检查器

进入游戏并运行时显示 [bevy-inspector-egui](https://github.com/jakobhellermann/bevy-inspector-egui) 的 `World Inspector` 面板，主菜单与暂停期间隐藏。它可查看实体层级、已注册反射的组件与资源，以及网格、材质等资产。人物输入与运动状态、演示参数和相机状态支持展开查看。

已启用组件变化高亮：带有 Bevy 变化标记的组件，其标题显示金色边框，便于观察移动、转向或编辑时的状态更新。

按 F3 释放光标后操作面板；光标位于面板、编辑字段或打开检查器菜单时，玩家输入会被屏蔽，避免编辑过程中移动、跳跃或拿放。点击面板之外的游戏区域恢复鼠标控制。检查器中的编辑只影响当前会话，不会写回 `settings.json` 。

## 设置

可从主菜单或暂停菜单打开 `Settings`。`Graphics` 的帧率、`Controls` 的鼠标设置和 `Audio` 的三项音量编辑独立草稿，切换分类保留编辑。音量实时预览，正在播放的声音也随之变化；其余设置在 `Apply` 保存成功后立即生效。

`Back` 或 Esc 丢弃未应用的编辑并恢复最近一次成功应用的音量。`Restore Defaults` 恢复全部设置草稿并立即预览默认音量，仍需 `Apply` 保存。

保存失败时显示英文重试提示，保留原设置文件、已应用设置和草稿；音量继续临时预览，返回时恢复已应用音量。

`Audio` 的 `Master Volume` 控制全部声音，`SFX Volume` 控制拾取、释放、落地及持握警告，`UI Volume` 控制菜单焦点、确认及返回提示。范围均为 `0–100%`，默认 `100%`；每行提供左右按钮、滑条和百分比，`0%` 显示 `Muted`。

按钮、左／右方向键和手柄每次调整 `5%`，鼠标点击或拖动滑条精确到 `1%`。拖动中不连续播放确认音，放开且数值改变后反馈一次；达到边界继续调整不反馈。`Test SFX` 播放一次拾取音，不触发拾取玩法。`Music Volume` 为不可操作的 `Coming Soon`。

玩家设置保存在工作目录的 `settings.json`，该文件由 Git 忽略，各工作目录保留自己的配置。文件缺失时使用代码中的默认值，首次在菜单中选择 `Apply` 后创建本地文件；也可手动创建或修改，文件修改在下次启动时读取。默认设置以 [GameSettings、CameraSettings 与 AudioSettings 的实现](../src/settings.rs) 为准：

```json
{
  "max_fps": 60,
  "camera": {
    "mouse_sensitivity": 0.003,
    "invert_y": false
  },
  "audio": {
    "master_volume": 100,
    "sfx_volume": 100,
    "ui_volume": 100
  }
}
```

| 配置 | 含义与有效值 |
| --- | --- |
| `max_fps` | 渲染帧率上限，必须为不小于 `60` 的整数，默认 `60`；`120`、`144` 等也有效。 |
| `camera.mouse_sensitivity` | 鼠标灵敏度，单位为弧度/像素，必须为有限正数。 |
| `camera.invert_y` | 为 `true` 时反转鼠标上下方向。 |
| `audio.master_volume` | 全部声音的音量百分比，必须为 `0..100` 的整数，默认 `100`。 |
| `audio.sfx_volume` | 游戏音效的音量百分比，必须为 `0..100` 的整数，默认 `100`。 |
| `audio.ui_volume` | 菜单音效的音量百分比，必须为 `0..100` 的整数，默认 `100`。 |

菜单帧率选项为 `60 / 90 / 120 / 144 / 165 / 240`；灵敏度每次调整 `0.0005`，菜单范围为 `0.0005..0.02`，界面按默认灵敏度 `0.003` 显示百分比。文件中的有效自定义值不因打开菜单而被修改，只有实际调整相应字段时才进入菜单选项范围。

省略配置字段时使用对应默认值。读取失败或内容无效时，记录警告并整体使用默认设置，保留原文件；未知字段也视为无效。保存成功后才更新已应用设置，失败时可保留草稿重试。保存机制见 [菜单与会话生命周期](architecture.md#菜单与会话生命周期)。

渲染上限不会改变人物移动、跳跃速度或相同鼠标位移对应的旋转幅度，也不会保证实际达到该帧率。性能不足时实际帧率会更低；操作系统调度也可能令帧率略低于上限。垂直同步是否能关闭取决于平台支持，关闭后可能出现画面撕裂。

## 会话日志

每次启动生成独立的 `logs/unix-<时间戳>_<会话UUID>.log`，历史日志保留。文件记录启动、版本与配置、关键状态变化、错误上下文及正常退出；运行日志与游戏存档分别管理。

出现问题时，提供对应会话日志、复现步骤、实际结果与预期结果，以及相关设置。提高日志详细程度的方法见 [日志排查](development.md#日志排查)，日志验收方法见 [日志检查与问题反馈](testing/game-acceptance.md#日志检查与问题反馈)。

## 音效

游戏提供菜单焦点、确认与返回反馈，以及成功拾取、主动释放、实际落地和持续持握失稳提示。静止鼠标、无效操作、重复选择当前分类、设置边界和普通静置接触不发声。具体触发条件见 [音效事件表](../assets/audio/events.md)。

音量控制与保存规则见 [设置](#设置)。暂停期间菜单声音和 `Test SFX` 仍可用。静音期间的新反馈直接丢弃，恢复音量不会补播；音效不改变输入与物理规则。

### 逐项试听

在浏览器打开 [试听页面](../assets/audio/audition.html)，点击条目播放或停止，可试听单个素材及合成环境循环；该环境音不在游戏中自动播放。试听页的监听音量独立于游戏设置。

直接打开本地文件时，页面读取同目录的 `audition_data.js` 静态快照，也可手动导入清单 JSON。浏览器限制本地文件访问，或需要读取最新清单时，在仓库根执行：

```powershell
python scripts/serve_audio.py
```

打开 [本机试听页](http://127.0.0.1:8765/audition.html)，结束后在终端按 Ctrl+C。服务只监听本机地址，不自动打开浏览器。

素材制作与检查见 [音频管线](audio.md)，文件参数以 [资产清单](../assets/audio/audio_manifest.json) 为准，来源与许可见 [归属记录](../assets/audio/ATTRIBUTION.md)。
