# 使用说明

本文说明当前演示内容、操作、设置、资源准备和问题反馈。玩法探索与确认状态见 [游戏设计](game-design.md)。

运行方式见 [README](../README.md#运行)，开发构建与发布说明见 [开发规范](development.md#构建与调试)，实际操作检查见 [游戏手动验收](testing/game-acceptance.md)。

## 当前内容

当前 demo 提供英文主菜单、暂停菜单、设置、操作说明和声音反馈。`Start Game` 直接创建一块平地、一名第一人称物理玩家和三个可搬方块。

人物可移动、跳跃和拿放方块，人物和物品受重力与碰撞影响。场景边缘以外会继续下落，需要从暂停菜单返回主菜单后重新开始。

## 菜单与占位功能

启动后进入英文主菜单。`Start Game` 进入演示场景，`Settings` 打开设置，`How to Play` 查看当前操作，`Quit` 正常退出。游戏内按 Esc 打开暂停菜单；`Resume` 或再次按 Esc 恢复，`Settings` 和 `How to Play` 返回后仍保持暂停，`Back to Main Menu` 清理当前玩法场景。再次选择 `Start Game` 会从初始场景开始。

鼠标可点击可用按钮；上／下方向键移动焦点，Enter 确认，Esc 返回，设置字段用左／右方向键或行内箭头调整。菜单也支持手柄方向键、南侧按钮确认、东侧按钮或 Start 返回。

可交互按钮在鼠标进入时高亮，离开后恢复普通纸色。键盘或手柄导航时显示当前焦点；实际移动鼠标可切回鼠标操作。当前分类和 `Apply` 不常驻高亮，帮助页的黄色编号块仅作装饰。

页面中的灰色 `Coming Soon` 行是不可操作的占位，键盘导航会跳过；当前菜单内容如下：

| 页面 | 可用功能 | `Coming Soon` 占位 |
| --- | --- | --- |
| 主菜单 | Start Game、Settings、How to Play、Quit | Continue、Multiplayer |
| Graphics | Frame Rate Limit | Window Mode、Resolution、VSync、Shadow Quality、Anti-Aliasing、View Distance |
| Audio | Master Volume、UI Volume | Music Volume |
| Controls | Mouse Sensitivity、Invert Camera Y | Rebind Keys |
| Accessibility | 暂无可调辅助功能 | UI Scale、Camera Shake |

Windows 与 macOS 的游戏内容区保持 16:9，初始为 `1280×720`，可拖动边缘或角等比例缩放；正常最小尺寸为 `960×540`。最大化使用屏幕工作区内最大的 16:9 窗口；macOS 禁用系统全屏与全屏平铺。

工作区小于最小尺寸时，优先保持窗口完整可见，菜单布局可能不完整。未适配原生比例约束的平台使用固定尺寸窗口；适配安装失败也禁用缩放并记录错误。

主菜单、暂停菜单和操作说明完整展示，不随滚轮或方向键滚动。设置中只有右侧纸色面板的标题、项目、说明与保存提示可以滚动；左侧分类、底部 `Restore Defaults / Apply / Back` 和页脚固定。

面板内容超出可用高度时显示滚动条。可在面板内使用滚轮、拖动滑块或点击轨道滚动；键盘焦点会自动滚入可视区域。内容无需滚动时隐藏滚动条，面板外的滚轮不移动页面。

## 资源准备

发布包需携带完整的 [assets/](../assets/)，保持字体与音频资源的原有路径结构。菜单使用 Lilita One 与 Atkinson Hyperlegible 字体，来源和许可证见 [字体来源](../assets/ui/fonts/SOURCES.md)。字体加载失败时检查本次 [会话日志](#会话日志) 中的文件路径。

## 当前操作

| 操作 | 行为 |
| --- | --- |
| 鼠标移动 | 直接控制镜头水平朝向和上下俯仰，无需按住右键；人物水平朝向随视角变化。 |
| W / S | 沿当前视角的水平前方加速前进或后退，松键后较快减速，不因后退改变朝向。 |
| A / D | 沿当前视角的水平左右方向加速横移，不改变朝向；斜向输入不会提高目标速度。 |
| 空格 | 地面起跳并落回地面；持续按住不会反复跳跃，空中不能再次起跳。 |
| E | 拿起范围内最近且无遮挡的方块，安全对齐到手前；持有时再次按下，从当前位置释放并保留速度，自然掉落。 |
| Esc | 打开暂停菜单，显示光标并冻结当前玩法；在暂停菜单再次按下恢复。 |
| F3 | 在游戏控制与检查器操作之间双向切换；检查器模式显示光标、停用玩法输入，游戏模拟继续运行。 |

游戏使用第一人称，镜头位于角色脚底上方 `1.65` 米，进入时平视，俯仰范围为 `-85°..85°`，持有物品可见。

暂停时停用玩法输入；恢复后重新捕获鼠标，忽略自由光标阶段积累的位移。

角色能够推动自由方块，也会受到外力影响。拿起物品后，若对齐路径持续受阻，箱体会自动释放；安全对齐后，箱体随人物稳定移动与转向。直走时手持箱与其他物体碰撞，人物和箱体作为整体响应并保持持握。转身路径被阻挡时，箱体在转动前的安全位置自动释放，视角继续转动。

手动和自动释放均保留实际位置与速度，箱体可继续滑动、翻滚和落地。人物可持箱移动和跳跃。60／120 FPS 的检查方法见 [游戏手动验收](testing/game-acceptance.md)。

## 灰盒场景

平地尺寸为 `40×1×40 m`，默认顶面位于 `Y = 0`。玩家使用脚底为原点的胶囊物理身体，场景中的可见几何为平地与三个纯色方块。方块默认边长为 `0.6 m`，尺寸由原型参数决定。

开始时直接装配当前场景，暂停保留位置、速度和持有关系。返回主菜单清理平地、玩家、方块、控制者、相机与灯光，重新开始恢复初始布局。

## 世界检查器

进入游戏并运行时显示 [bevy-inspector-egui](https://github.com/jakobhellermann/bevy-inspector-egui) 的 `World Inspector` 面板，主菜单与暂停期间隐藏。它可查看实体层级、已注册反射的组件与资源，以及网格、材质等资产。人物输入与运动状态、演示参数和相机状态支持展开查看。

已启用组件变化高亮：带有 Bevy 变化标记的组件，其标题显示金色边框，便于观察移动、转向或编辑时的状态更新。

按 F3 进入检查器模式后，可点击、编辑、拖动或滚动面板；光标位于面板外时也保持该模式，WASD、空格、E 和鼠标位移均不控制角色。再次按 F3 恢复游戏控制，检查器继续显示。窗口失焦时自动释放光标，重新获得焦点后按 F3 恢复；主菜单与暂停期间 F3 不捕获鼠标。检查器中的编辑只影响当前会话，不会写回玩家设置文件。

切换前先松开其他按键和鼠标按钮，结束拖拽与字段编辑并关闭弹出菜单；切换不承接尚未结束的输入手势。恢复游戏控制时忽略自由光标阶段的鼠标位移。

## 设置

可从主菜单或暂停菜单打开 `Settings`。`Graphics` 的帧率、`Controls` 的鼠标设置与 `Audio` 的两项音量编辑独立草稿，切换分类保留编辑。`Apply` 保存成功后才更新已应用设置并立即生效，音量编辑期间实时预览。

`Back` 或 Esc 丢弃未应用的编辑并恢复最近一次成功应用的音量。`Restore Defaults` 恢复全部设置草稿并预览默认音量，仍需 `Apply` 保存。

保存失败时显示英文提示，原设置文件与已应用设置不变，草稿与音量预览保留以便重试，返回时恢复已应用音量。

当前 Audio 页提供 `Master Volume` 与 `UI Volume`，有效范围均为 `0–100%`，默认 `100%`，两项共同决定已接入菜单声音的音量。左右按钮、方向键与手柄每次调整 `5%`，鼠标滑条精确到 `1%`，`0%` 显示 `Muted`。拖动结束且数值改变时反馈一次，`Music Volume` 显示不可操作的 `Coming Soon`。

玩家设置由 Bevy 原生设置插件保存为用户配置目录下的 `io.github.fedoraiver.demo/settings.toml`，同一用户的各工作目录共享配置。Windows 路径为 `%LocalAppData%\io.github.fedoraiver.demo\settings.toml`，macOS 为 `~/Library/Preferences/io.github.fedoraiver.demo/settings.toml`，Linux 为 `${XDG_CONFIG_HOME:-~/.config}/io.github.fedoraiver.demo/settings.toml`。文件修改在下次启动时读取，首次选择 `Apply` 后创建文件。

文件缺失时采用默认值；读取失败或文件无效时整体回退默认值，并保留原文件。只读取原生 TOML，不读取工作目录下的旧设置文件。默认值以 [设置类型实现](../src/settings/config.rs) 为准：

```toml
[game]
max_fps = 60

[game.camera]
mouse_sensitivity = 0.003
invert_y = false

[game.audio]
master_volume = 100
ui_volume = 100
```

| 配置 | 含义与有效值 |
| --- | --- |
| `max_fps` | 渲染帧率上限，必须为不小于 `60` 的整数，默认 `60`；`120`、`144` 等也有效。 |
| `camera.mouse_sensitivity` | 鼠标灵敏度，单位为弧度/像素，必须为有限正数。 |
| `camera.invert_y` | 为 `true` 时反转鼠标上下方向。 |
| `audio.master_volume` | 总音量，必须为 `0..100` 的整数，默认 `100`。 |
| `audio.ui_volume` | UI 分类音量，必须为 `0..100` 的整数，默认 `100`。 |

菜单帧率选项为 `60 / 90 / 120 / 144 / 165 / 240`。`Controls` 的鼠标灵敏度可直接输入百分比，`100%` 对应默认灵敏度 `0.003`，支持小数与科学记数法。点击输入框或导航至输入框后按 Enter 开始编辑；编辑时方向键移动文本光标，Enter 结束编辑，直接点击 `Apply` 也会保存当前输入。有效输入转换后必须为有限正数，不受固定步进或菜单上下限限制。空值、零、负数及超出可保存精度范围的输入会阻止应用，切换分类保留尚未完成的文本；`Back / Esc` 丢弃未应用编辑。文件中的有效自定义值不因打开或应用菜单而被舍入到预设值。

省略配置字段时使用对应默认值。读取失败或内容无效时记录警告；未知字段视为无效。保存机制见 [设置草稿与持久化](architecture.md#设置草稿与持久化)。

帧率限制不会改变人物移动、跳跃速度或相同鼠标位移对应的旋转幅度，也不会保证实际达到该帧率。限制按近似帧间隔执行，短时采样可能高于设定值；性能不足或操作系统调度也可能使实际帧率更低。垂直同步是否能关闭取决于平台支持，关闭后可能出现画面撕裂。

## 会话日志

每次启动生成独立的 `logs/unix-<时间戳>_<会话UUID>.log`，历史日志保留。文件记录启动、版本与配置、关键状态变化、错误上下文及正常退出。

出现问题时，提供对应会话日志、复现步骤、实际结果与预期结果，以及相关设置。提高日志详细程度的方法见 [日志排查](development.md#日志排查)，日志验收方法见 [日志检查与问题反馈](testing/game-acceptance.md#日志检查与问题反馈)。

## 音效

当前接入菜单焦点、确认与返回声音，使用 `bevy_kira_audio` 播放。静止光标、无效操作、当前分类重选和设置边界不触发反馈，暂停菜单继续播放 UI 声音。静音期间的新请求直接丢弃，恢复音量后只播放后续操作的反馈。

可在浏览器打开 [逐项试听页面](../assets/audio/audition.html) 评审清单中的音频素材，监听音量独立于游戏设置。素材来源、清单与检查方法见 [音频管线](audio.md)。
