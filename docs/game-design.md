# 游戏设计

`demo` 是一个基于 Rust 与 Bevy 的实践项目，用于探索游戏制作、积累经验并提升游戏制作水平。当前玩法尚未确定。

## 设计状态

当前没有已确认的游戏类型、世界设定、玩家目标、核心玩法循环或成长机制。后续设计根据实际探索与验证逐步明确，具体需求与讨论记录在相关 Issue 中。

现有场景、角色、物理交互和其他功能是可继续调整的实验基础，不据此预设后续玩法。当前可用能力、操作和配置集中记录在 [使用说明](usage.md)，实现方式见 [当前架构](architecture.md)。

## 文档维护

玩法方向确认后，在本文记录目标、规则和确认状态；尚未确认的想法明确标为建议或待定，不写成既定要求或已实现能力。具体任务、开发进度与单次验证结果按 [任务跟踪约定](agents/issue-tracker.md) 记录在对应 Issue 或 PR。
