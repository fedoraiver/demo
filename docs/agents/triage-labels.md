# Triage labels

技能中的五个分诊角色与 GitHub 标签一一对应。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，代理无需额外人工背景即可实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |

这些标签已在 `fedoraiver/demo` 中配置。技能提到某个角色时，使用表中对应的标签名称。
调整分诊状态时按技能流程更新这些标签，保留与分诊无关的标签。
今后变更标签名称时，同步更新本表与 GitHub 仓库标签。
