# 分诊标签映射

分诊角色使用同名 GitHub 标签。

| 角色／标签 | 含义 |
| --- | --- |
| `needs-triage` | 维护者需要评估 |
| `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | 需求已明确，代理无需额外人工背景即可实施 |
| `ready-for-human` | 需要人工实施 |
| `wontfix` | 不予处理 |

目标仓库以 [任务跟踪约定](issue-tracker.md) 为准。

调整分诊状态时按技能流程更新这些标签，保留与分诊无关的标签。

今后变更标签名称时，同步更新本表与 GitHub 仓库标签。
