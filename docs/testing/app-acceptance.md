# 应用自动化验收

本页列出无窗验收构建的客观条件和脚本覆盖范围。五个脚本分别驱动菜单与暂停、设置、物理交互、人物移动与镜头、会话日志，覆盖 22 个已脚本化子项。运行方式见[自动化启动准备](README.md#自动化启动准备)。根据画面临时调整操作时，按[探索性应用验收](README.md#探索性应用验收)记录观察结果。专项步骤见[窗口策略](window_policy.md)、[世界检查器](inspector.md#世界检查器验收)和[音频验收](audio.md#音频验收)。

## 判定与证据

脚本读取类别标题及固定格式的表格，标题、已实现编号与脚本须保持同步。每行子项使用固定编号。表中「脚本」项由所属脚本执行，「待实现」项保留验收义务及所缺证据。报告记录子项编号、预期、实际和证据。可用状态为 `passed`、`failed`、`blocked`、`not_run` 和 `not_implemented`。`not_implemented` 表示覆盖缺口，不影响总脚本通过；环境阻塞需要说明缺失的能力或条件，失败后尚未到达的子项记为未执行。运行过程及证据记入报告，对应 Issue 或 PR 引用报告和进程输出。

键鼠从原生 Bevy 消息进入实际业务链路。使用 BRP 准备场景时，报告记录写入值与就绪状态。准备完成后，验收动作由输入驱动。应用状态和磁盘用结构化断言，日志证据引用 `process_output` 文件的路径和行号。驱动为子进程设置 `RUST_LOG=info` 和 `NO_COLOR=1`，以纯文本捕获 INFO 日志。退出前后的捕获和持物等观测只有落实到相应子项才计入覆盖。

截图记录游戏离屏渲染的捕获结果、尺寸和文件位置。外观判定需要可用图像和批准的基线，连续画面需要将采集帧与输入、固定步及场景状态对齐。首次和有意改变的视觉基线由用户批准。

人物移动与镜头的关键截图关联对应操作以及截图前后的 BRP 状态。查看画面时，记录可见的场景变化、与状态采样的对应关系及证据缺口，并将观察随本次报告保留。脚本的子项状态由自动断言判定。

## 菜单与暂停

| 子项 | 执行方式 | 操作与通过条件 |
| --- | --- | --- |
| **MENU-01.main_menu_ready** | 脚本 | 启动后，主菜单资源和可操作按钮就绪，布局可用于输入，玩法角色尚未创建。 |
| **MENU-01.appearance** | 待实现 | 用图像基线验证 `Grey-boxing`、纯色背景、按钮与纸张面板、页脚键帽和说明可见。 |
| **MENU-02.keyboard_navigation** | 脚本 | 用方向键导航，观察焦点和导航输入来源变化，再用 Enter 进入帮助并用 Esc 返回。 |
| **MENU-02.mouse_help_and_back** | 脚本 | 点击 `How to Play` 后进入帮助，捕获 `help.png`，并通过鼠标点击 Back 返回主菜单。 |
| **MENU-02.focus_and_placeholders** | 待实现 | 检查 Enter 长按与手柄导航、全部按钮悬停和静止光标下的焦点保持、`Continue` 与 `Multiplayer` 占位项不触发操作，以及帮助卡片、键位和两种返回操作。 |
| **MENU-05.layout_and_scroll** | 待实现 | 用布局和图像验证主菜单、帮助和暂停无重叠裁切且保持位置。设置页在溢出时支持滚轮、滑块、轨道和键盘聚焦滚动，分类栏、底部按钮及页脚位置保持。切页、返回或改变逻辑视口后核对滚动状态。 |
| **MENU-07.start_game_scene** | 脚本 | 点击 `Start Game` 后进入运行状态，观察一名角色、三个方块及玩法相机，确认鼠标捕获且主菜单相机已清理。 |
| **MENU-07.pause_input_isolation** | 脚本 | 在起跳后腾空时通过 Esc 进入暂停，核对逻辑光标的显示状态并捕获 `pause.png`。暂停时注入键鼠，核对角色、方块和镜头状态保持。 |
| **MENU-07.pause_mid_action** | 待实现 | 分别在持箱和方块下落时暂停并验证姿态冻结。 |
| **MENU-08.resume_session** | 脚本 | 从暂停打开帮助并返回暂停，核对场景保持。通过菜单恢复运行和鼠标捕获，核对沿用当前场景并继续落地。 |
| **MENU-08.pause_subpages_and_input_reset** | 待实现 | 从暂停访问设置并返回，核对场景冻结。用 Esc 恢复时镜头保持，暂停前的跳跃和拿放请求不会补发。 |
| **MENU-09.restart_session** | 脚本 | 暂停回主菜单后观察旧玩法实体清理。再次开始，核对仅生成本轮的一名角色、三个方块和一台玩法相机。 |
| **MENU-09.quit_button** | 待实现 | 点击主菜单 `Quit` 后核对进程退出码。 |

## 设置

| 子项 | 执行方式 | 操作与通过条件 |
| --- | --- | --- |
| **MENU-03.tabs** | 脚本 | 进入设置并依次点击四个分类，观察实际选中的分类，并确认各页保留 Apply 和 Back。 |
| **MENU-03.controls_and_layout** | 待实现 | 验证占位项不可修改，分类和底部操作可见，当前字段说明与焦点对应。验证图形页帧率控件、控制页纵轴与[灵敏度](ui.md#鼠标灵敏度验收)、音量控件及滑块外观。 |
| **MENU-04.frame_rate_discard** | 脚本 | 通过菜单选择不同帧率档位后返回，核对生效值和磁盘保持原值，重新进入设置后草稿取生效值。 |
| **MENU-04.frame_rate_apply** | 脚本 | 选择不同帧率档位并点击 Apply，核对提示、生效值和用户 `settings.toml` 中的 `[game].max_fps`。 |
| **MENU-04.settings_restored** | 脚本 | 游戏退出后核对磁盘仍是本次写出的版本，验证文件恢复为测试前的原始字节或原有的缺失状态。外部修改或归属不明时保留备份，记录恢复失败。 |
| **MENU-04.settings_scroll_and_defaults** | 待实现 | 连续点击、键盘调整各字段，确认滚动位置及滑块保持。核对切换分类或重进设置的滚动初始化，以及 `Restore Defaults` 后取消和 Apply 的不同结果。 |
| **PHYS-08.settings_fallback** | 待实现 | 分别用帧率 `59` 和 `60` 重启，核对字段警告、生效配置值、文件原值和退出恢复。 |

## 物理交互

| 子项 | 执行方式 | 操作与通过条件 |
| --- | --- | --- |
| **PHYS-01.initial_scene** | 脚本 | 从主菜单开始，观察地面、三个方块和接地角色，核对相机初始偏航与俯仰接近零、相对角色的高度及眼位设置均为 `1.65 m`，捕获 `game.png`。 |
| **PHYS-01.scene_appearance** | 待实现 | 核对渲染中的灰色地面、纯色方块与镜头无遮挡。 |
| **PHYS-03.movement_dynamics** | 待实现 | 核对加速、松键减速、斜向目标速度与俯仰下水平移动方向，实测推动方块和阻挡。WASD 的基本方向见 `VIEW-01.wasd`。 |
| **PHYS-04.single_jump** | 脚本 | 从接地状态按住空格，观察起跳、升起、落地，核对长按仅触发一次起跳。 |
| **PHYS-04.airborne_input** | 待实现 | 空中再次按空格，核对跳跃未叠加，跟随镜头眼位随高度变化。 |
| **PHYS-05.pickup** | 脚本 | 在初始场景按 E，核对最近方块进入持有状态。 |
| **PHYS-05.carry_collision** | 待实现 | 三个方块分别验证对齐、持箱移动及跳跃、碰撞时的共同阻挡、途中扫掠受阻的自动放下和边缘接触。核对箱体可见和长按 E 的重复触发边界。 |
| **PHYS-06.release** | 脚本 | 释放 E 后重新按下，核对同一方块解除持有并自然下落。 |
| **PHYS-06.release_dynamics** | 待实现 | 移动、转身及跳跃中释放，核对姿态、惯性和落地反应。远处无法拾取，返回可再拾取。 |

F3 相关的 `PHYS-07` 见[检查器验收](inspector.md#世界检查器验收)。`PHYS-09` 的日志证据归[会话日志](#会话日志)。

## 人物移动与镜头

| 子项 | 执行方式 | 操作与通过条件 |
| --- | --- | --- |
| **PHYS-02.relative_yaw_pitch** | 脚本 | 在捕获状态下分别注入水平和垂直鼠标位移，按当前灵敏度和纵轴配置核对偏航、俯仰及实际镜头朝向。记录初始镜头与两次转动各自完成时的画面。 |
| **PHYS-02.pitch_limits** | 脚本 | 核对俯仰分别停在 `+85°` 和 `-85°`，确认再次向边界输入后仍保持。 |
| **PHYS-02.facing_and_unused_binding** | 待实现 | 核对观察时角色水平朝向、位置和侧倾，验证按下或长按 I 无业务效果。 |
| **VIEW-01.wasd** | 脚本 | 转向并俯仰后分别按 W、A、S、D，核对移动意图及相对视线的水平位移。松键后确认意图归零、角色停稳且偏航保持。在移动前及 W、A 各自松键停稳后截图。 |
| **VIEW-01.diagonal_and_stop** | 待实现 | 核对四组斜向输入和推动方块时的阻挡。 |
| **VIEW-02.continuous_tracking** | 待实现 | 移动中快慢转向、反向及整圈回转，需要对齐的连续状态与渲染样本验证镜头、持物同步和起停平稳。 |
| **VIEW-03.carried_view** | 待实现 | 空手和持三个方块分别验证眼位、握姿、转动阻挡、释放和跳跃呈现。 |
| **VIEW-04.carried_pause** | 待实现 | 持箱移动时暂停和恢复，核对持物姿态、镜头和重新开始后的初始场景。 |
| **VIEW-05.fall_and_restart** | 脚本 | 用 BRP 将角色放到地面边缘内侧，确认接地停稳后按 S 走出地面并观察下落。暂停回主菜单后重新开始，核对实体重建及角色、方块和镜头的初始状态。记录边缘内侧就绪、下落后暂停和重新开局的画面。 |
