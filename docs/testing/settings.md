# settings 测试

[测试指南](README.md)说明分层和执行边界；实机步骤由用户执行。

## 单元与集成验证

运行 `cargo test --locked settings::tests` 检查设置字段的反射序列化、范围校验、草稿与渲染限帧。无窗口用例使用内存数据。涉及页面的草稿与控件交互还运行 [UI 测试](ui.md)。

- `max_fps` 保持整数格式。`59` 回退至默认 `60`，`60` 与 `120` 保留输入值。
- 总音量和 UI 音量接受 `0–100`。相机灵敏度和音量的越界值仅回退对应字段，保留同组的有效值。警告给出字段名、原值和采用的默认值。
- 草稿保留已有的合法自定义值，只有校验通过的草稿才能替换生效设置。
- 无窗口测试在空渲染子应用中装配 `FramepacePlugin`，验证初始 60 FPS、同帧应用 120 FPS、`u32::MAX` 对应 1 ns，以及调整期间的固定模拟时间步。测试推进主应用以读取插件采用的帧间隔。
- 灵敏度覆盖 `0.01`、`10.00` 和默认 `5.00` 的单位换算、越界回退及 `0.01` 量化。仅调整其他字段时，应用草稿保留未修改的合法原始角速度。

## 窗口验收

在实际窗口中分别应用 60 和 120 FPS，保持游戏窗口可见，观察其获得及失去焦点时的帧率。性能足够时，两种焦点状态下的帧率都应接近各自上限。配置生效与保存见[设置验收](app-acceptance.md#设置)，固定模拟频率与配置上限日志见[会话日志验收](app-acceptance.md#会话日志)。
