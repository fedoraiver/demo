# ui 测试

[测试指南](README.md)说明分层与执行边界；客观应用检查使用验收构建与脚本，人工范围见[补充验收](game-acceptance.md)。

## 菜单、设置与资产的无窗口验证

菜单回归只使用最小 `App / World`、必要的状态／输入插件和 BSN 实体树，不安装窗口后端或渲染器。UI fixture 显式安装第三方 `EnhancedInputPlugin`，通过与 `GameUiPlugin` 共用的普通注册函数安装菜单生命周期、真实输入与页面，不依赖 `FirstPersonPlugin`。跨功能 fixture 显式安装所需项目 Plugin；需要状态时安装 `GameFlowPlugin` 并进入运行状态，没有应用状态时复用 `game_flow::configure_feature_order`，不补跑系统代替实际调度。应覆盖：

- 页面只暴露可用的 `MenuButton` 动作，导航序号连续；`Continue`、`Multiplayer` 和所有 `Coming Soon` 设置不进入焦点或业务动作列表。
- 菜单动作使用真实 Enhanced Input 绑定，长按确认／返回不重复执行；鼠标和键盘请求进入同一消费入口，页面切换后旧请求不穿透。
- 原生 Picking 与 Button 的实际链路覆盖主键同帧按下／释放、文字子节点命中、右键／中键、取消后再次按键及重建旧目标；只接受主键菜单动作，音量滑条同帧完整点击仍采样并结束，其他指针键不改变主键高亮或执行请求。按钮取得原生焦点后，Space 只产生未消费的原生 `Activate`，Enter 仍只经 Enhanced Input 执行一次。
- 文字测量、按钮移入／移出、输入来源切换与重建后的焦点按 [文字布局与高亮回归](#文字布局与高亮回归) 检查。
- 主菜单、暂停与帮助在支持的 16:9 视口内完整显示且不滚动；设置仅右侧纸色面板内容可滚动。具体布局、滚动条和刷新边界见 [文字布局与高亮回归](#文字布局与高亮回归)。
- `AppState` 的 `MainMenu / Running / Paused` 切换管理会话与暂停；离开主菜单创建会话，返回主菜单清理平地及业务实体，`Running / Paused` 切换保留角色、箱体、控制者、相机与持有关系；暂停当帧清意图并停止物理步。恢复不补发跳跃／拿放请求。从暂停设置同时通过键盘和旧按钮返回后，连续两帧仍保持暂停。
- 主菜单与暂停释放光标并停用玩法上下文；恢复运行跳过自由光标位移。F3 可在游戏与检查器模式间双向切换；检查器模式停用全部玩法输入，面板内外点击均不恢复捕获。
- 当前 Audio 页提供总音量与 UI 音量两行调整，每行箭头、滑条、百分比／`Muted` 测量有效并进入连续导航，Music 为占位。拖动不重建页面或连续发送确认音，释放且值改变时反馈一次。
- 灵敏度数字编辑覆盖原生按键、粘贴、输入法、最后字符与 Enter 同帧、直接 `Apply`、失焦规范和跨分类保留未完成文本。滑条覆盖两端取值、同帧按下／释放、越界拖动及取消后重新捕获，数字编辑和滑条联动时检查本帧实际填充几何。
- 设置字段、恢复默认与应用结果原位刷新，保持控件身份、焦点和有效滚动偏移；离开重进或切换分类才重建页面。
- 离开主菜单清理背景根及菜单相机，保留无关相机。

检查入口为 [状态与暂停测试](../../src/game_flow/tests.rs)、[菜单测试](../../src/ui/tests.rs) 和 [设置测试](../../src/settings/tests.rs)。可按模块选择运行，例如：

```powershell
cargo test --locked settings::tests
cargo test --locked ui::
```


### 文字布局与高亮回归

共享文字或按钮样式变更必须覆盖所有使用场景，开发约束见 [UI 布局与高亮规范](../development.md#ui-布局与高亮规范)。检查使用真实字体测量、页面 BSN 树和布局系统；字符串、字体句柄或组件存在不能证明文字有尺寸。

| 范围         | 检查场景与边界                                                                                                                                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 短标签与正文 | 非空短标签的 `ComputedNode` 宽高大于零、`TextLayoutInfo` 字形非空；覆盖页脚键帽／说明、帧率箭头／数值／FPS、音量名称／箭头／百分比／`Muted`、底部三个操作、帮助编号与键位。有限宽正文受约束并实际形成多行。                    |
| 灵敏度控件   | `0.01 / 1.23 / 10.00` 的 `EditableText` 实际字形与尺寸有效，滑条在左、数字框在右，控件完整位于设置面板内。 |
| 固定页面     | 用项目字体在 `960×540`、`1280×720`、`1920×1080` 虚拟视口检查 Main/Pause/Help 的按钮、页脚及全部文字位于视口内；帮助包括三张卡片的正文、标题、编号与键位。滚轮与焦点导航不改变页面偏移，仅高度变化也须重建页面。                |
| 设置滚动范围 | 按实体祖先关系确认只有右侧纸色面板中的标题、项目、说明和保存提示滚动；左侧分类、底部操作和页脚位置固定。在这些固定区域和外层空白滚动不改变偏移，面板内越界焦点能滚入，固定按钮导航不触发滚入。                                 |
| 滚动条       | 覆盖溢出／无溢出、滑块比例与两端位置、行／像素滚轮、拖动与轨道分页。无溢出时偏移归零并隐藏；零范围／零行程不产生非有限数值。轨道和滑块不盖正文或固定操作，显隐时预留宽度不变，避免折行引起反复显隐；轨道与滑块不进入按钮导航。 |
| 原位刷新     | 从非零偏移和已有焦点出发，通过实际请求调整字段、恢复默认、应用及显示成功／失败提示；文字更新，`MenuRoot`、`MenuScroll`、轨道、滑块、字段按钮身份和焦点不变。合法偏移完整保留，内容变短时只夹取到新范围，滑块同步。             |
| 页面生命周期 | 切换分类或离页再进入会销毁旧树、生成新页面并初始化焦点与偏移；视口变化更新布局，旧实体销毁后拖动状态不残留。                                                                                                                   |

指针检查触发真实 `PointerScroll` 与滚动条 Observer，并用面板／滑块的正向滚动证明事件已到达，再验证固定区域不滚动；只检查事件类型或样式会假通过。最小环境须注册输入所需的 `Window` 组件类型与 `ScrollbarPlugin`，不安装窗口后端或渲染器。

[UI 测试](../../src/ui/tests.rs) 包含短文字／换行、页面布局、原位刷新与滚动检查。短文字／换行使用内嵌字体与虚拟视口，不能证明项目字体加载或实际输出；页面尺寸覆盖上述三个视口，不代表全部分辨率均已验证。

高亮回归使用实际 BSN 页面与样式系统，至少覆盖以下过程，并在每次 `app.update()` 后断言背景和边框：

| 过程                                                                                 | 应验证的结果                                                                                         |
| ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 对每个可交互按钮执行 `None → Hovered → None`，并检查按下后释放／移出的状态           | 移入高亮、离开恢复；此前被点击或保存为 `MenuFocus` 的按钮也不残留高亮。                              |
| 主菜单、暂停、帮助及四个设置分类逐一切换                                             | 所有可交互按钮遵循相同规则，特别检查当前分类和 `Apply`；帮助编号与占位项无按钮动作且不进入焦点列表。 |
| 鼠标静止在另一按钮上，通过真实 Enhanced Input 动作导航，再切换页面重建或原位更新草稿 | 只保留导航焦点，旧悬停与重建产生的新 `Hovered` 都不抢焦点；草稿更新不替换焦点按钮实体。              |
| 导航后真实移动鼠标到同一按钮内部、空白区域、窗口外，或点击按钮                       | 即使 `Hovered` 没有变化也切回鼠标来源；空白与窗口外无遗留导航高亮，点击按钮只产生一次语义请求。      |

新增控件纳入上述页面与 [UI 测试](../../src/ui/tests.rs) 覆盖；模拟 `Hovered` 和 `Pressed` 只确认状态与样式，真实命中、字体显示与裁切按 [菜单验收](ui.md#英文菜单与暂停验收) 检查。

## 英文菜单与暂停验收

客观应用条件见[应用自动化验收](app-acceptance.md#菜单与暂停)，验收运行方式与执行边界见[测试指南](README.md#agent-验证边界)。主观评价及确实无法可靠驱动的专项见[人工补充验收](game-acceptance.md)。

### 鼠标灵敏度验收

1. 确认左滑条与右数字框双向同步，数字框通常显示两位小数。拖动至 `0.01` 和 `10.00`，检查滑条方向键以 `0.01` 为步长，并在轨道外释放或窗口失焦后确认捕获已结束。
2. 输入 `1.234` 后按 Enter 或点击别处，应显示 `1.23`。直接选择 `Apply` 也应提交，并在[设置文件](../player-guide.md#设置)中写入约 `0.0009225` 弧度/像素。编辑时方向键移动文本光标。输入空值、`0`、`10.01` 或 `1e` 后，应用应拒绝该草稿，切换分类保留输入内容。
3. 仅修改其他字段并应用时，合法的原始角速度应保持精度。`Restore Defaults` 应恢复为 `5.00`，保留数字框字号，结束先前的编辑和待处理粘贴。
4. 分别应用 `0.01` 和 `10.00` 后恢复游戏，检查水平转向仍可用。相同的水平鼠标位移在 `10.00` 时对应的转向幅度约为默认值 `5.00` 的两倍。完成后恢复原设置。
