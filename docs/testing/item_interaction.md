# item_interaction 测试

[测试指南](README.md)说明分层和执行边界；已脚本覆盖与待实现的实机条件见[物理交互验收](app-acceptance.md#物理交互)。

## 持物与视角同步的无窗口验证

使用最小 `App` / `World`、手动时间和必要的变换传播插件，检查固定模拟与逐帧显示姿态的边界；不加载窗口、渲染器或完整游戏场景，不调用 `App::run`。

Avian 的物理步位于 `FixedPostUpdate`。涉及速度、重力、接地或碰撞的回归必须执行实际物理调度，不能只运行 `FixedUpdate` 后把施力当成已经完成运动；使用最小物理插件和几何碰撞体即可，无需窗口或渲染插件。

| 场景                                          | 应验证的结果                                                                                                                                                                                                                                                         |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 手动时间步为 `Duration::ZERO`，本帧没有固定步 | 输入更新观察角度后，`RunFixedMainLoop` 在插值之后仍依次同步角色水平朝向、`HeldTarget`、第一人称镜头和人物 `Visibility`；物理位置和速度不被额外推进，跳跃与交互请求不被额外消费。                                                                                     |
| 渲染更新按 120／240 Hz 推进，固定模拟为 60 Hz | 拾取对齐完成后，包括没有固定步的交替帧在内，实际箱体 `Transform` 和 `HeldTarget` 都与本帧人物呈现位置和朝向一致；运行 `PostUpdate` 后，视觉子实体 `GlobalTransform` 正确传播箱体根姿态及子实体局部偏移。持握箱保持固定局部姿态，第一人称镜头与人物可见性保持一致。                     |
| 固定步正常执行                                | 角色朝向仍在移动施力、跳跃、交互之前同步；物理步骤按固定时间积分，逐帧同步不重复施力或执行拿放。                                                                                                                                                                     |
| 释放物体后继续改变视角                        | `HeldBy`、`HeldTarget` 与挂接状态已移除，箱体恢复独立动态刚体与自由碰撞，人物质量还原；释放保留安全世界姿态与实际线速度、角速度。后续视角变化不再移动箱体，物体仍按惯性、重力和碰撞运动，视觉子实体姿态正确传播实际根姿态及子实体局部偏移。                                                |
| 默认眼位与观察角度                            | 相机初始俯仰为 `0°`，俯仰限制 `-85°..85°`；位置为角色脚底上方 `1.65`。鼠标位移更新同一组水平角与俯仰角，角色移动与持握只读取水平角。                                                                                                                                 |
| I 键未绑定                                    | 通过设备输入消息模拟 I 键按下、持续按住与重新按下，第一人称相机角度、目标和眼位不改变，人物与持物状态不受影响。                                                                                                                                                      |
| 鼠标模式、失焦及无效关联                      | F3 手动释放或重新捕获鼠标，释放期间停用玩法输入，点击不改变捕获模式。窗口失焦释放、回焦后须按 F3 恢复。暂停与无效控制关联不应用观察位移，恢复捕获首帧跳过自由光标位移。[检查器输入专项](inspector.md#无窗口集成验证) |
| 人物视觉与方块可见性                          | 第一人称只隐藏对应的 `CharacterVisual`；相机或控制者丢失、关联失效后人物恢复显示；方块视觉和其他角色不被隐藏。                                                                                                                                                       |

这些检查验证组件状态与调度结果，不能代替真实窗口中的鼠标手感、持箱虚影和视觉稳定性验收。

物理行为回归还应覆盖：输入后逐步加速、松键减速、斜向目标速度一致、外部冲量实际推动角色及后续主动制动、角色碰墙受阻与推动自由箱体、脚底接地及侧墙不接地、持握箱按碰撞层过滤而不充当支撑面、空中请求不重复跳跃、自由箱体落地、持箱受墙阻挡、释放保留速度、隔墙拾取过滤、同批次拾取不重复占用，以及持有者销毁或关系异常解除后清理目标、恢复碰撞并自然下落。场景装配测试检查角色根的物理组件、地面与箱体根的网格及物理组件，以及地面物理顶面等于配置、出生高度按地面高度和偏移计算。视觉子实体不重复添加刚体或碰撞体仍需检查，当前测试未断言此项。

### 避免测试掩盖帧间错位

异常现象和旧测试的漏检机制见[持箱转向错位复盘](../postmortem/2026-10-01-held-crate-frame-mismatch.md)。

初始化拾取关系可以先执行固定步，但输入后的本帧检查必须在 `app.update()` 返回时立即完成，不能先补跑模拟或手动调用同步系统。

新增或修改相机、转向和附件跟随时，检查以下测试条件：

- 用 `TimeUpdateStrategy::ManualDuration(Duration::ZERO)` 覆盖连续没有固定步的帧，并比较 `Time<Fixed>::elapsed()`，确认测试确实没有推进固定时间。
- 用 120／240 Hz 渲染更新与 60 Hz 固定模拟验证帧末姿态。每帧断言人物、持握目标和相机使用本帧角度，并确认运行中确实出现零固定步帧。单帧多个固定步时，确认鼠标位移不会重复应用，运动只按模拟时间推进。
- 安装无窗口的 `TransformPlugin`，同时检查业务根实体的 `Transform` 与本帧 `PostUpdate` 后的根和模型子实体 `GlobalTransform`，覆盖用于渲染的最终姿态。窗口组件可仅作为输入所需的 ECS 数据，不能安装窗口后端或渲染插件。
- 释放后先确认 `HeldBy`、`HeldTarget` 移除，再连续转动视角。零固定步时物理位置和速度应保持；有固定步时允许物体自然移动，需确认它不再追逐持握目标，不能只检查持有状态。
- 比较世界矩阵分解得到的旋转时，注意四元数 `q` 与 `-q` 表示同一旋转。应比较实际前向、上向向量或等价旋转，避免把符号变化误判为同步错误。

检查入口为 [第一人称与动作路由测试](../../src/first_person/tests.rs)、[物品跨帧与旋转测试](../../src/item_interaction/tests.rs) 和 [灰盒场景测试](../../src/scene_assembly/tests.rs)。通过真实 E 绑定完成拾取和短暂对齐后再发鼠标输入，所有场景保留帧末立即断言：

| 转向与清理场景 | 必须保留的边界                                                                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 完整旋转路径   | 起终点均空、途中扫过薄墙仍受阻；覆盖正反半圈、整圈、角度 wrap、凸箱、偏心复合箱、贴墙转入／转离及已有地面接触。新阻挡在同帧于转动前安全位置放下，镜头完成角度；直走受阻仍持握。 |
| 空旷地形       | 用三角网格或方盒地面确认整圈包络无其他障碍，覆盖不同始角、微转、正反半圈及零／单固定步。离地箱在零固定步帧仍被持有，不能忽略地面、关闭自动放下或缩小箱体规避误报。              |
| 有限墙面       | 用最小有限三角面、方盒墙和偏心复合箱覆盖多种始角，证明整段路径与障碍分离。不能只查端点或把有限墙面当无限平面，帧末检查持握、视觉与镜头。真实薄墙和新接触仍须阻挡。              |
| 生命周期清理   | 拿放、人物／箱体销毁、关系异常解除后恢复质量、碰撞与独立实体身份并清除代理。                                                                                                    |

拿放和阻挡的已脚本覆盖与待实现条件见[物理交互验收](app-acceptance.md#物理交互)，连续帧效果见[人物移动与镜头](app-acceptance.md#人物移动与镜头)。
