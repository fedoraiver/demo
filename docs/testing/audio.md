# audio 测试

[测试指南](README.md)说明分层和执行边界；实机步骤由用户执行。

## 音频无窗口验证

```powershell
cargo test --locked audio
cargo test --locked ui::
cargo test --locked settings::tests
```

音频测试只解码文件或使用通道数据，不安装设备输出。当前用例覆盖已接入声音的清单、解码、冷却与并发，以及 UI 通道的默认基准增益、总音量与分类音量相乘、零音量静音及恢复不补播。菜单检查真实导航、悬停、确认、返回、输入去重，以及滑条释放反馈。管线回归使用隔离素材覆盖额外分类、事件映射、导入、清单、质量检查、来源日期及媒体哈希。声音技术检查见 [音频管线](../assets/audio/README.md)，实际听感和输出由用户按 [音频验收](audio.md#音频验收) 确认。

## 音频验收

以下步骤覆盖当前接入的菜单声音与音量设置。

1. 在主菜单用鼠标移入按钮，再用方向键或手柄改变焦点，真实焦点变化应有短反馈。静止光标、按钮内移动、无效操作、当前分类重选和单按钮页面的无效导航不反复发声。
2. 打开 `Settings → Audio`，确认 `Master Volume / UI Volume` 两行默认 `100%`。按钮与左右导航每次调整 `5%`，拖动滑条能得到整数百分比，改变期间立即预览，释放且数值改变后只确认一次。任一音量为 `0%` 时菜单静音，恢复后只对新操作发声。
3. 切换分类保留草稿与预览，`Back / Esc` 恢复已应用音量。`Restore Defaults` 预览默认值，返回时丢弃，`Apply` 成功后重新启动应保留两项音量。保存失败保留草稿预览、原文件与已应用值，返回后恢复已应用音量。
4. 暂停中重复菜单导航与音量编辑，声音继续反馈，角色与方块保持暂停。恢复与返回主菜单使用返回音，正常退出停止声音。
5. 检查会话日志中的 `Audio pipeline initialized`、资源请求、菜单请求与混音变化。素材来源和技术检查见 [音频管线](../assets/audio/README.md)，问题反馈附会话日志及音量设置。
