# character 测试

测试分层、运行方式与执行边界见[测试指南](README.md)。

## 无窗口集成验证

运行 `cargo test --locked character::tests`，并结合 [场景与物理验证](scene_assembly.md)。

这些检查覆盖组件、资源、层级和物理结果。实际窗口的客观条件与覆盖状态见[物理交互验收](app-acceptance.md#物理交互)。

身体静置足够时间后须进入 `Sleeping`，继续静置时须保持休眠，自身回写不能将其唤醒；随后主动移动、跳跃或外部冲量必须在首个真实固定步改变位移与速度。首步加速度位移按实际固定步长与 `SubstepCount` 的半隐式 Euler 序列计算，不能用改变速度但未完成物理积分的状态作为通过依据。

角色回归明确断言休眠、持续静置及移动后同一步唤醒和积分。跳跃与外部冲量回归在静置后确认接地，但未先断言 `Sleeping`，因此不能据此确认休眠后跳跃或冲量的首步行为已覆盖。

高速薄墙及动态身体 CCD 的具名回归由 [物理测试](physics.md#高速碰撞回归)维护。
