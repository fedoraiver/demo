# physics 测试

[测试指南](README.md)说明分层和执行边界；实机步骤由用户执行。

## 无窗口集成验证

运行 `cargo test --locked physics::tests`；休眠首步的测试条件见 [角色测试](character.md)，高速碰撞的条件见下方 [高速碰撞回归](#高速碰撞回归)。

## 高速碰撞回归

高速薄墙回归 `character_ccd_blocks_high_speed_velocity_and_impulses_at_different_yaws` 用 `SpeculativeCcd::new(0.001)` 限制推测接触距离，以不同水平 yaw 验证角色受到初速度或外部冲量后仍被扫掠阻挡。先完成一次高速物理步建立引擎预测邻域，再创建薄墙并检查后续实际固定步；用 `CcdFilter::NONE` 显式关闭扫掠的对照应穿过同一薄墙，避免 Avian 的自动 CCD 或推测接触造成假通过。不能仅在零 yaw 下验证，也不能将线性算法当作与当前非线性算法等效的替代。无窗口结果验证物理行为，不能证明真实渲染 FPS；具体耗时和执行结果记录在关联 Issue 或 PR 中。

`character_ccd_keeps_dynamic_body_protection_after_plugin_upgrade` 验证高速角色被动态薄墙逐帧阻挡，以 Avian 默认过滤的穿墙对照证明动态过滤位必要。`approaching_fast_dynamic_bodies_keep_their_order_with_predictive_neighbors` 覆盖角色与箱体、两个箱体高速相向运动：使用真实身体工厂，先推进一个尚未交会的高速步建立预测邻域，再逐帧保持顺序与最小间距；只移除双方 `SpeculativeCcd` 的对照应在随后的首个交会步交叉，证明速度扩张邻域参与候选生成，不能仅靠扫掠组件存在判断安全。

用户检查移动、跳跃和碰撞见 [物理交互验收](physics.md#物理交互验收)。

## 物理交互验收

选择 `Start Game` 后按下面九项检查当前 demo。设置文件的字段、默认值和有效范围见 [玩家指南](../player-guide.md#设置)。

1. 开始后以第一人称看到灰色平地与三个纯色方块。初始镜头位于角色脚底上方 `1.65 m`，水平向前，人物碰撞身体不遮挡镜头。
2. 站立并移动鼠标，镜头可左右观察和上下俯仰，人物水平朝向同步变化且位置不变；持续向上下移动鼠标，应在 `-85°..85°` 的边界停止，无侧倾。按下或长按 I 不改变视角、人物位置或拿放状态。
3. 转动镜头后按 W / S，人物沿视角的水平前后方向逐渐加速，松键后较快减速；按 A / D 时横移，后退和横移都不改变朝向。斜向输入不会提高目标速度，镜头持续跟随；上下观察不改变水平移动方向。用人物推自由方块，方块应因碰撞移动，人物不应直接穿过方块。
4. 按空格时人物起跳并自然落地，第一人称眼位随人物升降；持续按住或在空中再次按下不会额外起跳。
5. 分别靠近三个方块按 E，箱子从当前位置短暂安全对齐到手前。空地中慢速、快速转向并移动、跳跃，完成对齐后的箱体应与人物稳定保持同一相对姿态，不出现滞后；上下观察不改变水平持握位置。持箱直走与其他方块碰撞时，人物与箱子应作为整体响应并保持持握，人物不能追进箱子。转身时箱体路径碰到其他方块，应在转动前的安全位置自动放下，人物和镜头继续正常转向；起终点都空但途中经过障碍也要触发。贴地切向和远离已有接触不能误放。实际箱体始终可见，长按 E 不重复拿放。
6. 松开后再次按 E，方块从当前物理位置释放，保留速度并自然下落，不能瞬间落到面前地面。分别在站立、移动、快速转向与跳跃时释放，检查自由箱体的惯性、落地碰撞和滚动；继续转动和移动，箱子不再追逐手前目标。走远后按 E 不会拾取，走近后可以再次拿起。
7. 按 [世界检查器](../player-guide.md#世界检查器) 的切换前约束结束交互，再按 F3，光标应显示，游戏模拟仍运行，WASD／空格／E 和鼠标位移均不控制角色；点击检查器内外均保持该模式。再次按 F3 恢复游戏控制，检查器仍显示。切换到其他窗口后应释放鼠标，回到游戏窗口后仍需按 F3 恢复。恢复时镜头不应因释放期间的位移突然跳转。Esc 的暂停与恢复另按[菜单验收步骤](ui.md#英文菜单与暂停验收)检查。
8. 默认设置下用外部帧率监测工具观察帧率：性能足够时应接近 60 FPS，性能不足时可低于上限。把 `settings.json` 中的 `max_fps` 改为 `120` 后重新启动，观察上限提高，相同输入下人物加速、减速、跳跃与箱体掉落过程应保持一致，相同鼠标位移对应的旋转幅度也应相同。在 60 FPS 与 120 FPS 设置下都重复第 2～6 项，确认人物和箱体运动平滑、无固定步交替造成的抖动或虚影；持箱时的固定握姿与整体阻挡、释放后的惯性应在两种帧率下都保持一致，第一人称无人物遮挡。两次会话日志中的 `simulation_hz` 应均约为 `60`，`max_fps_after` 分别为 `60` 和 `120`。另将 `max_fps` 改为 `59` 后重新启动，本次日志应记录设置无效的警告及回退上限 `60`，原设置文件仍保留 `59`；改为 `60` 后重新启动，应成功加载且不再出现该警告。完成后恢复默认设置 `60`。
9. 正常关闭窗口后，按 [日志检查与问题反馈](session_log.md#日志检查与问题反馈) 核对本次会话的启动配置、移动、起跳着陆、拿放、相机捕获及退出记录，再次启动确认会话文件隔离。

同批次拾取预留、持有者销毁或关系异常解除后的目标清理、恢复碰撞与自然下落由无窗口回归验证。
