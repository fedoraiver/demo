# Agent Note: 共用设置文件的应用验收

Status: implemented

## Problem

[验收启动音量](2026-11-22-acceptance-startup-volume.md)通过验收专用设置目录加载测试配置。普通和无窗验收启动需要共用同一个用户设置文件，测试配置的准备与恢复由脚本负责。

## Decision

普通和验收启动统一使用 `GameSettingsPlugin` 的设置路径。每个验收脚本先在设置文件同目录独占创建恢复备份，再写入零总音量的测试配置。测试进程退出后，脚本确认当前文件由本次运行写入，再恢复原字节或原有缺失状态。

## Changes

[设置插件](../../../src/settings/mod.rs)统一从用户配置目录加载及保存设置。[验收驱动](../../../scripts/acceptance/driver.py)在启动前暂存设置并在发送输入前通过 BRP 核对总音量。[设置文件处理](../../../scripts/acceptance/settings_file.py)负责备份、写入和恢复。运行、异常和手工恢复规则保留在测试指南中。[共用设置与恢复](../../testing/README.md#共用设置与恢复)

## Alternatives considered

验收专用目录可在运行期间隔离普通游戏的设置写入。共用文件使应用只保留一条加载和保存路径，也让设置场景覆盖玩家使用的实际保存位置。

## Consequences

测试运行期间，共用文件含有测试配置。独占备份约束不同工作目录的验收脚本并发，其他游戏实例和外部编辑器仍需在测试结束后使用此文件。检测到不明写入后保留备份和磁盘证据。直接启动验收构建时使用玩家当前的设置和音量。

## Verification

检查已有配置和起初缺失两种状态，覆盖载入零总音量、设置保存、进程退出后恢复、重复启动和冲突保留备份。应用验收按[自动化启动准备](../../testing/README.md#自动化启动准备)串行执行，证据随报告和会话日志保留。
