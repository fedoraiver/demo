# Agent Note: Bevy 0.20.1 补丁升级

Status: implemented

## Problem

Bevy 0.20.0 通过 `bevy_image` 使用 `ruzstd 0.8.3`。该版本处理不可信压缩数据时可能耗尽进程内存。[RustSec 公告](https://rustsec.org/advisories/RUSTSEC-2026-0344.html)

## Decision

定向升级 Bevy 至 `0.20.1`，沿用已有兼容版本的插件。这样可以把回归定位到 Bevy 补丁及其必要的传递依赖更新。

## Changes

[Cargo.toml](../../../Cargo.toml) 要求 Bevy `0.20.1`，[Cargo.lock](../../../Cargo.lock) 锁定 Bevy `0.20.1` 和包含安全修复的 `ruzstd 0.9.1`。同步更新[当时的启动日志](https://github.com/fedoraiver/demo/blob/6425fd329a62f0b9c7842c3917c74b7e810a7937/src/session_log/lifecycle.rs)、[调度导出清单](https://github.com/fedoraiver/demo/blob/054f6fdf596d2f6b4c9c0ce9ce6999250e28da4f/src/inspector/schedule_dump.rs)和[导出测试断言](https://github.com/fedoraiver/demo/blob/054f6fdf596d2f6b4c9c0ce9ce6999250e28da4f/src/inspector/tests.rs)中的 Bevy 版本。

[实体命名回归的测试项目](https://github.com/fedoraiver/demo/blob/054f6fdf596d2f6b4c9c0ce9ce6999250e28da4f/tools/check-entity-names/tests/check.rs)采用 Bevy `0.20` 兼容范围，从当前项目锁文件开始离线解析。CI 预取项目锁定的补丁版本，本地已有的临时锁文件也会在 fixture 初始化时得到更新。

## Alternatives considered

可通过构建脚本从锁文件注入版本，以减少后续重复维护。移除 Bevy 内置音频依赖和更新第三方插件也可以单独验证。本次限定为补丁升级，采用现有版本记录方式。

## Consequences

架构图读取器用锁文件核对导出清单中的版本，并核对清单与当前源码的指纹。升级前的调度导出已失效，生成新架构图时需要重新导出。[清单校验](https://github.com/fedoraiver/demo/blob/054f6fdf596d2f6b4c9c0ce9ce6999250e28da4f/docs/diagrams/src/debugdump-input.mjs)

## Verification

检查默认和 `debugdump` 两种配置能否按锁文件编译。用无窗口测试检查会话日志、调度导出、场景与持物变换。真实窗口的脚本输入和截图证据见[应用验收](../../testing/app-acceptance.md)。普通构建的输入切换见[检查器验收](../../testing/inspector.md#世界检查器验收)，设备声音与听感见[音频验收](../../testing/audio.md#音频验收)。
