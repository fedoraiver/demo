# Agent Note: 维护文档的事实与归属审查

Status: implemented — 已核对维护文档并修正与当前实现不符的说明。

## Problem

架构、测试和资产文档已调整归属，开发记录也扩大到设计、实际改动与抉择。需要核对现有维护文档是否与当前实现一致，以及移动后的阅读入口能否承接原有约束。

## Decision

按工程规则与资产、运行时架构与测试、架构图与事故记录三个范围核对当前工作区。只修正有源码、配置或文档规则依据的问题，保留已有工作区改动；开发与决策记录遵循 [Notes 约定](../../README.md)，事故记录遵循 [复盘约定](../../../postmortem/README.md)。

## Changes

- 修正 [检查器测试](../../../testing/inspector.md) 的捕获测试入口，并将 [物理回归](../../../testing/physics.md) 的覆盖说明限定为实际断言的行为，不声称测量 CPU 开销。
- 更新 [架构图维护](../../../diagrams/maintenance.md) 的打包责任、环境前提和字体上下文说明，几何输入版本改为链接实现中的唯一来源；[架构图测试](../../../diagrams/testing.md) 改为当前的大文本、UTF-8 与原子替换边界，保留失败恢复和流式调用图检查。
- 从 [架构图视觉规范](../../../diagrams/README.md#节点与连线视觉规范) 删除与集中样式重复的颜色、轮廓和宽度清单，保留类别语义、选择、显示与交互约束。
- 精简 [App 总览](../../../architecture/README.md) 中的局部场景实现，以及 [第一人称](../../../architecture/first_person.md)、[角色](../../../architecture/character.md) 和 [设置](../../../architecture/settings.md) 中仅复述 `Local` 存储的说明；保留应用生命周期、跨功能关系、状态清理和日志边界。
- 修正 [开发规范](../../../development.md) 的采样字段与架构图验证范围、[玩家指南](../../../player-guide.md) 的地面减速和空中惯性说明，并移除面向玩家的音频后端细节。
- 将 [角色测试](../../../testing/character.md) 中的休眠行为要求与现有回归覆盖分开，明确休眠后跳跃和外部冲量的覆盖缺口；清理第一人称和设置架构文档末尾多余空行。

## Alternatives considered

只检查链接：能够发现路径与锚点问题，但无法判断当前行为、必要约束和内容归属是否正确，因此同时核对正文与实现。

## Consequences

测试入口与其覆盖范围一致；可直接从实现查阅的版本和样式清单不再维护第二份副本。修订只涉及文档，已有产品代码、工具、配置与资产内容保留，三张 App Mermaid 图未作调整。角色休眠后的跳跃与冲量仍缺少明确的休眠前置断言，文档不将其计为已覆盖。

## Verification

检查事实、内容归属、本地链接与锚点，并逐项比较修订前后的责任、时序和失败边界。静态文档检查不能代替外链、远端标签实际状态、真实窗口、设备或游戏验收；具体执行结果与未验证事项由交付说明或对应 Issue／PR 记录。
